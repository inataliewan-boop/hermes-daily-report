背景与核心逻辑

为什么必须打、为什么难、怎么破
为什么打

赔付率决定利润率

为达成利润率 ≥1%，赔付率必须压回 40%。但已连续恶化：5月40.65% → 6月43.46% → 7月45.17%，不干预年底将突破 46%。

为什么难

分母有效贡献打折

9-12月新单财保当年只释放 15.43% 进分母，卖 1 亿财保仅增 1,543 万已赚；反推纯靠卖保费所需新单边际 LR 为 -7.26%（不可行），因已有 2,187万 历史包袱。

核心结论：仅靠做大分母无法达成。必须 分子端控赔 800~1,000万 + 分母端结构调优（A/B档占比70%+）+ 12月等待期纯稀释 三管齐下，才能把预测的 42.6%~43.2% 拉回 40%。
最大风险：重疾处于赔付爬坡期（6-7月单月边际 55%~57%），若众民保中高端2026、尊享中高端等放量，将进一步蚕食控赔成果。

口径与测算框架

三个记账口径 × 核心精算等式
考核口径·已赚

赔付率 = 事故制赔付 ÷ 已赚保费，按保障期逐期释放，退保停掉剩余。这是看板/考核口径。

业务口径·财保

按保单满额记账（120元/年投保单即记120元财保），退保负向冲销。业务追踪口径。

换算关系

9-12月新单已赚 ≈ 财保 × 15.43%（释放系数）。卖1亿财保当年仅增1,543万已赚。

核心精算等式
全年赔付率 = ( 1-8月累计终极赔付 + 9-12月存量释放赔付 + 9-12月新单当年赔付 ) ÷ ( 1-8月累计已赚 + 9-12月存量释放已赚 + 9-12月新单当年已赚 ) ≤ 40%

测算细节：恒等式校验 & E_new 反推（展开）

恒等式①：E_new = Σ(W_m × k_m)。中性场景月均0.85亿：0.85亿×0.6170 = 5,245万（恒等成立）。

  • 9月：0.85亿×0.2249 = 1,912万
  • 10月：0.85亿×0.1841 = 1,565万
  • 11月：0.85亿×0.1342 = 1,141万
  • 12月：0.85亿×0.0738 = 627万

E_new 反推：E_new = Ω_gap/(40%-M_max)。当 M_max=34.32%，Ω_gap=2,187万 → E_new = 3.85亿（远高于中性5,245万，故不可行）。此式为反推公式，非恒等式校验。

附录 · 背景参考与关键概念

关键概念与口径释义（10条）

① 已赚 vs 财保：财保按保单满额记账；已赚按保障期逐期释放。9-12月新单财保当年只释放15.43%进分母。

② 为什么疗效打折：释放系数k_avg=15.43%（9月22.5%/10月18.4%/11月13.4%/12月7.4%）。1亿财保→1,543万已赚→净稀释贡献(40%-25%)×1,543万=231万。

③ 为什么纯靠卖到不了40%：M_max=40%-Ω_gap/E_new。中性E_new=5,245万、Ω_gap=2,187万 → M_max=-1.70%不可行。

④ 12月冲量最划算：12月新单赔付≈0，1亿财保净贡献40%×738万=295万 > 其他月份231万。

⑤ Ω_gap≈2,187万是什么：存量历史超赔包袱。1-8月+9-12月存量释放已赚4.24亿，按40%标准应赔1.696亿，但实际1.915亿，超赔2,187万="历史欠债"。

⑥ 为什么设LR_exist三档：重疾在赔付爬坡期（6-7月边际55-57%）。保守40%/中性45%/悲观50%，建议45%为底线、50%做压力测试。

⑦ 单月边际55-57%是什么：6月56.8%、7月55.1%，即每月新发生赔款占当月已赚的55-57%，是恶化最直接证据。

⑧ 意外险197.5%要紧吗：规模小（已赚147万）、单笔大案击穿，对大盘影响+0.5pct。设熔断线，不影响大盘。

⑨ A/B档70%+逻辑：A档每卖1亿净贡献231万稀释；B档约120万；C/D档每卖1亿新增赔付80-120万。A/B占比越高稀释效率越高。

⑩ 口径区分：考核用看板"已赚"（事故制赔付÷已赚）；业务追踪用"财保"（按保单满额记账）；换算：9-12月新单已赚≈财保×15.43%。
