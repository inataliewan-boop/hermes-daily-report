🏛️ 政策新规

《财产保险公司保险产品开发管理规定》正式发布（金规〔2026〕9号）

金融监管总局发布《规定》，系对《财产保险公司保险产品开发指引》的系统性修订，共8章41条。六大要点：①压实公司主体责任，条款费率承担法律责任；②列示八类禁止开发情形（禁止承保投机风险、无实际保障内容等）；③单设附加险章节，细化附加险开发要求；④要求成立由主要负责人牵头的产品管理委员会；⑤强化产品全生命周期管理（评估-修订-清理注销）；⑥建立内部问责机制。消费者保护方面要求条款通俗易懂，免责内容须以足以引起投保人注意的方式提示。

So What：健康险（短期医疗险等）多在财险公司体系内报备，此新规直接影响产品上架流程：八类禁止情形+附加险细化规则意味着产品报备材料要求趋严，产品委员会审议机制或将拉长创新产品的过会周期——上架SOP中建议预留更长的合规评审buffer。

💡 产品亮点

众民保2026：带病可投 + 家庭共享免赔，重构普惠医疗险标准

目标人群：高龄/带病/高危职业等非标体家庭。产品设计：免健康告知、无职业限制、全龄可保（30天-105周岁），一般既往症可赔；核心创新是家庭成员共享免赔额（社保内外两个责任免赔额共享）+家庭投保费率优惠最高省20%；配套慢病原研药责任（0免赔、60%赔付、月购药1次）。差异化：从个人免赔转向家庭共享免赔，直接提升理赔使用率——家庭任一成员出险即摊薄全家免赔门槛，解决传统医疗险"理赔使用率偏低"痛点。市场反馈：中高端版上线10天保费破1.4亿，系列4年累计50亿。

So What：家庭共享免赔是被低估的设计创新：它把"降低赔付门槛"做成了家庭投保的转化钩子（拉新+提额+费率优惠三合一）。做家庭单/亲子单运营时，"共享免赔"可作为核心卖点包装测试。

👥 消费者洞察

带病体人群的"风险画像差距"远超传统模型假设

商涌科技副总裁张华引用一项覆盖4.5万人、长达6年的医保理赔研究：校正年龄性别后，有住院史患者赔付风险是未住院者的2.23倍；并发症从0个增至6个，医疗费用风险从1.83倍攀升至7.53倍；无并发症人群6年费用年均仅涨0.98%。结论：同样"确诊5年的2型糖尿病"，按时服药血糖平稳者与多次大额住院者是完全不同的风险资产，但传统风控模型把二者归为一类。

So What：这组数字可直接用于带病体产品的风险分档逻辑论证：免健康告知≠放弃风险识别，"认出最差的2%（赔付率被放大5倍+的客群）"是产品可持续的关键——给核保/定价团队做内部分享时是现成素材。

🎯 市场机会

机会一：带病体保险的"家庭化"改造窗口

众民保的家庭共享免赔验证了"把带病体保障装进家庭单"的路径：带病成员是家庭投保的"钩子人群"（一人带病→全家投保→费率优惠）。行业数据显示带病体供给远小于需求，而家庭单恰好解决带病体产品两大难题——逆选择分散（家庭池稀释个体风险）与获客成本（一次触达多成员）。

So What：可评估在家庭险/门诊险产品线上增加"带病成员家庭共享免赔"或"带病家属投保入口"的可行性，以家庭为单位做续保经营，提升M13留存。

机会二：理赔体验数据资产化，做续保期运营抓手

行业理赔时效已内卷至0.13-0.36天、获赔率99%+，但多数用户对此无感知。把理赔体验数据（时效/获赔率/直付案例）做成续保期的个性化触达素材（"去年我们为你提速了X天"），是低成本高转化的运营资产。

So What：续保率是Q4考核重点（M13留存30%权重），理赔数据素材库可纳入用户运营Q4动作清单。

📱 用户运营专栏

带病体客群的续保经营三板斧（众民保实践）

众安王顺披露带病体客户留存的三个抓手，可迁移到健康险通用续保运营：

① 稳住续保预期：产品虽为非保证续保，但"正常理赔客户不会被拒保"作为明示承诺，给客户长期信心——本质是把续保规则透明化，降低决策不确定性；

② 产品迭代反哺老客户：老客户无论是否理赔，续保即可升级到最新产品方案——把"续保"从重复动作变成"权益升级"动作；

③ 保障责任随连续投保年限提升：与理赔记录无关的年限权益（NCD式设计），激励客户长期留在保障池，避免"用完即走"。

So What：三条均可映射到现有产品的续保权益设计：明示续保规则→老客升级通道→年限递增权益。尤其第③条"与理赔记录脱钩"对医疗险用户心智极友好，值得在续保弹窗/企微触达中做A/B验证。

📐 精算小课堂

免健康告知产品的"逆选择定价"难题：2%客群如何吞噬利润

免健康告知产品放弃事前核保筛选后，最差2%客群的赔付率被放大超过5倍，但其满期保费贡献几乎不变——风险与保费严重错配。应对思路（行业实践）：①内部风控模型对客户做风险量化评分（年龄+性别+投保行为+既往医疗风险综合打分），拦截极端逆选择；②基于医保理赔大数据做病种风险分组定价（并发症数量是核心因子：0→6个并发症，费用风险1.83→7.53倍）；③"严重既往症清单"动态管理，封堵新药催生的逆选择窗口。一句话原理：免告知不等于免风控——把核保从"投保前拦截"后移到"投保后精细化分层"，定价精度决定产品生死。

延伸：这与赔付率管控直接相关：事故制赔付率的分子端（赔款）主要由高风险尾部客群驱动，分层定价能力=赔付率管控能力。行业趋势是用AI大模型做健康状况识别+风险分档，替代传统"一刀切"核保规则。
