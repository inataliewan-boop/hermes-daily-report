政策新规

中保协发布三大医疗险示范条款＋《商业健康保险药品保障推荐清单（第一版）》

11月10日中保协2026年度第三次例行新闻发布会发布《一般商业医疗保险（短期）示范条款》《一般商业医疗保险（长期）示范条款》《城市定制型商业医疗保险示范条款》及《商业健康保险药品保障推荐清单（第一版）》。这是落实「十五五」规划纲要健全多层次医疗保障体系、金融监管总局《关于推动健康保险高质量发展的指导意见》的具体举措。药品清单首批遴选58款推荐药械：适应症覆盖肺癌、肝癌、血液肿瘤等高发癌种及神经母细胞瘤等目录内罕见病肿瘤；其中1类创新药25款、2类改良型新药2款，合计占比近半；基本医保目录外自费药32款、占比近六成。

So What：条款框架统一后，医疗险条款层面的差异化空间收窄，竞争焦点将转向药品目录、健康服务与理赔体验；药品推荐清单为创新药责任设计提供了行业统一参考目录，新品开发的特药责任对齐成本大幅降低。

行业动态

前三季度保险业原保费5.26万亿元，「报行合一」降本增效显效

中保协11月10日发布会数据：2026年前三季度保险业原保费收入5.26万亿元，同比+0.9%；赔款与给付支出1.94万亿元，同比+3.9%。人身险公司积累的寿险和长期健康险责任准备金超28万亿元，较年初+12.7%。手续费及佣金支出同比-5.2%（财产险公司-3.1%、人身险公司-6.4%）。发布会同期发布科技、绿色、普惠、养老、数字保险五份年度发展报告。

So What：费用端持续压缩验证「报行合一」成效，费用竞争空间收窄，资源将向产品价值与服务投入迁移；赔付增速（+3.9%）快于保费增速（+0.9%），赔付率管理仍是行业主要矛盾。

药品推荐清单背后的创新药责任开发窗口

精算小课堂

费率可调长期医疗险：赔付率为什么「压不住」以及调费机制怎么触发

长期医疗险风险特征：医疗通胀叠加存量保单年龄结构老化，赔付率增速趋势较快，调费机制可部分对冲但存在不确定性。行业通行的费率调整触发条件（以条款约定为例）：①上一年度产品赔付率≥85%；或②上一年度赔付率≥行业平均赔付率−10%。其中赔付率＝（年度赔款＋年末未决赔款准备金−年初未决赔款准备金）÷（年度保费＋年初未到期责任准备金−年末未到期责任准备金）——分子分母都含准备金提转差，评估时点选择对数字影响显著。SOA《The Actuary》中文版（平安人寿精算团队）提示：通过「健康体×既往症体」分组暴露与人均赔付成本结合做赔付率展望，可在产品研发期提前识别调费有效性风险。

行业对照：短期健康险端，2022年度138家险企赔付率中位数37%，但9家公司超100%红线、最高797%——均值健康掩盖的尾部风险同样存在于长期险的调费假设中。（注：赔付率分布为2023年披露的2022年度数据，供方法论参考）

So What：评估长期医疗产品时，盯赔付率绝对值不如盯「赔付率增速＋调费触发距离」两个动态指标；本周落地的药品成本表为医疗通胀假设提供了新的行业基准。
