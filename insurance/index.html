📋 行业动态

8月单月保费-10.3%，全年最严峻的业绩考验

金融监管总局数据显示，前8个月全行业原保险保费收入48,191.63亿元，同比仅微增0.4%，增速较1—7月回落1.5个百分点；8月单月保费5,302亿元，同比下滑10.3%，为年内连续第四个月负增长，且降幅较7月扩大1.7个百分点。截至8月末，保险业总资产44.57万亿元，较年初增长7.9%。市场预期三季度全行业净利润同比或下滑约50%。

So What：资产端扩张（总资产+7.9%）与负债端收缩（单月-10.3%）背离，说明行业已进入"存量资产负债表管理"阶段。对健康险运营的含义很直接：新单拉不动时，续保率、交叉销售、单客价值就是唯一的增长杠杆，用户运营从"辅助职能"变成"主承压部门"。
📎 新浪财经 / NEW财金 · 2026-10-09

健康险结构分化：财险公司+14.56%，人身险公司微降

2026年前5个月，人身险公司与财产险公司合计实现健康险原保险保费收入5,521亿元，同比增长3.9%。其中财产险公司健康险保费1,644亿元，同比大增14.56%；人身险公司健康险保费收入同比微降。同期财产险公司整体原保费7,979亿元，同比增长2.23%。

So What：健康险3.9%的增速明显跑赢行业整体（0.4%），是少数还有增量的品类；而14.56%的财险系增速背后是短期医疗险的互联网化与件均下沉。众安所在的赛道方向是对的，压力在"同质化+费率战"而不是需求端。
📎 证券时报 · 2026-06-28

互联网保险2025年保费破1.2万亿，中介持续出清

行业公开数据显示，2025年互联网保险整体保费规模突破1.2万亿元，同比增幅20%，人身险业务贡献超七成。传统险企线上渠道保费占比达63%，首次反超线下。同时保险专业中介法人机构降至2,506家、连续6年下滑，2026年上半年又有124家退出，出清主体以纯通道型机构为主。

So What：线上已是第一入口（63%），流量红利转向"渠道效率"竞争；通道型中介出清对自营平台是利好——用户资产留在自有 App/小程序里的价值上升。

🏛️ 政策新规

《财产保险公司保险产品开发管理规定》修订发布，11月1日施行

2026年10月9日，国家金融监督管理总局修订发布《财产保险公司保险产品开发管理规定》，自2026年11月1日起施行，同步废止原保监会2016年印发的《财产保险公司保险产品开发指引》等两份旧文件。核心变化：

  • 明确8类禁止开发的违规产品：无实际保障内容、单纯以降价或涨费/恶意炒作为目的的产品；承诺未出险返还保险费或其他不当利益的产品；无保险利益、约定不明确的产品等；
  • 首次对附加险开发设专章规范，压实产品开发主体责任；
  • 强化消费者权益保护，补齐近年市场产品乱象的监管漏洞。
So What（众安相关度极高）：短期健康险正由财险公司经营，本规定直接适用于百万医疗、门诊险等主力产品线。三条立即要自查的红线：①"未出险返保费""健康管理服务返还"类责任设计；②附加险打包是否单独论证充足性；③条款中"无实际保障内容"的赠险/权益拼接结构。建议在产品开发与商详审核 SOP 里加一道"新规8类禁止"清单式核验。

🔮 前沿趋势

趋势一：从"卖保险"到"管健康"，健康管理成为跨界主战场

6月以来多家保司在健康管理侧密集落子：太保健康与蚂蚁健康联合推出 AI 互动式健康险产品，平安健康险与乐刻运动合作。行业共识正在形成——健康人群渗透率已高、保费增速放缓，单纯事后经济补偿的产品无法匹配升级需求，从被动理赔转向主动健康干预、从单一产品竞争转向全域生态比拼。

So What：健康管理若只做"赠品"，无法进入定价闭环；真正的分水岭是能否把干预行为数据回灌到赔付率模型里。可验证的动作：为健康管理权益绑定可追踪的行为指标（步数/体检/用药依从），设置"行为-赔付"相关性分析，一年后给权益定价。

💡 产品亮点

带病体赛道进入"可保即可赔"竞赛：三家打法对比

  • 太保 蓝医保·中高端医疗险（2026）：仅设两条健康告知，行业首创取消既往症限制——体况异常人群符合告知即可投保且相关疾病按约定赔付，实现"可保即可赔"；投保年龄拓至0—65周岁，支持未成年人单独投保，家庭单至高八五折。
  • 人保财险 人人安康（众享版）：带病可投（放宽结节、高血压、糖尿病）、首次/非续保投保年龄放宽至70周岁、严重既往症以外的"一般既往症"纳入赔付；配套"理赔明白卡"与理赔流程可视化。
  • 众安 众民保·中高端医疗险2026：围绕带病人群小额住院、术后康复、慢病用药三大痛点扩保障；民营医院增至183家，肿瘤特药不限清单、涵盖国内已获批7款CAR-T；一般疾病可选特需/国际/VIP部，重大疾病自动拓展。风控侧做"减法"：明确严重既往症清单、一般既往症阶梯式等待期、择期手术首年赔付比例过渡、新药适应症设边界。
So What：三家都指向同一结论——带病体的竞争点已从"能不能保"转为"赔不赔得干净"。太保用"取消既往症"打信任牌，人保用高龄+简化告知打普惠牌，众安用"保障加法+风控精细化减法"打可持续牌。真正的护城河在于：谁能把既往症分层做得更细，谁就能在同样保费下承担更多风险。这也是我们赔付率目标（40%）最直接的抓手。

👥 消费者洞察

"赔付率低"正在变成消费者信任问题

21世纪经济报道统计59家财险公司2025年个人短期健康险综合赔付率：中位数仅41.09%，34家（近六成）赔付率同比下降，6家出现负值，4家超过100%。报道指出，赔付率表现既是费用结构与渠道模式的结果，也折射定价策略与风险管理能力差异；在"保费是否过高、保障是否充分"的争议升温之际，如何在提升保障获得感与维持可持续经营之间取得平衡，成为短期健康险的关键命题。

So What：中位数41%意味着百元保费里约六成去了费用与利润——这在自媒体时代极易被放大成"保险不值"的舆论。运营侧的对冲手段不是降价，而是把赔付可视化：理赔明白卡、案件进度可查、拒赔理由结构化解释（人保已在做）。这是续保与M13留存最便宜的抓手。
📎 21世纪经济报道 · 2026-03-23

健康险总盘：2025年有望首破万亿，但增速已降至个位数

泰康长寿时代研究院《健康险2026展望报告》显示，截至2025年11月，中国商业健康险保费规模9,440亿元，同比增长2.39%，按此增速推算全年有望首次突破万亿。安联《2026全球保险业发展报告》则指出，2025年中国健康险保费增长2.0%，但预测未来十年将以年均8.1%领跑全球健康险。

So What：短期2%与长期8.1%的落差说明：需求没消失，是当前产品没接住。增量在老龄化、慢病、带病体、中高端医疗；不在"再卖一份百万医疗给健康年轻人"。

🎯 市场机会

机会一：惠民保从"增量扩张"转向"存量优化"，二次开发窗口打开

许闲团队《2025年城市定制型商业医疗保险（惠民保）知识图谱》显示，截至2025年7月31日全国累计推出313款产品，正常运营稳定在202款；2025年新增仅9款，2025年前7个月停售仅12款（2023年同期停售超70款）。超过60%的停售产品存续期仅1期。2026版地方产品持续升级：深圳惠民保88元/人/年、5家共保体承办、保障期2026年7月—2027年6月；春城惠民保设基础版/升级版、按年龄分级定价，并把国家商保创新药目录纳入特药。

So What："低增量、低退出"=市场格局锁定，抢新城市不划算了，存量项目的续保率提升与"惠民保→商业健康险"的向上转化才是真机会。惠民保用户是已教育过、有医保数据、价格敏感的人群——用低门槛门诊险/小额住院做承接转化，是最短的链路。

机会二：中高端医疗+特需资源，是"低赔付率焦虑"的解药

太保蓝医保中高端取消既往症限制、众民保中高端开放特需/国际/VIP部与183家民营医院、人保放开70岁投保——中高端医疗正在成为带病体与中产的共同解。

So What：中高端客单价高、责任边界清晰、赔付可控（特需/私立医院费用可议价），对"保费规模"和"赔付率"两个KPI同时友好。建议在2027年开门红产品规划中把中高端医疗作为结构性增量项，而不是百万医疗的加价版。

📱 用户运营专栏

案例拆解：水滴的私域分层与"行为标签驱动"转化 SOP

水滴的私域运营路径可拆成三层：

  • 客户分级：高潜（多份医疗险/已购重疾）→深度运营（企微1V1、人工顾问回访），目标加保与年金/寿险交叉销售；中等潜力（持有一份医疗险）→人工电销，目标重疾+家庭单；赠险边缘客户→轻度运营（机器人外呼）。
  • 场景再分：在单一医疗险内再按车主、宝妈、银行、单身、养老等场景切分，并分普通/中等/绩优/高绩优四层。
  • 节点 SOP：企微通过后欢迎语直达 H5/小程序 → 用页面行为数据打标签回流数据库 → 首次触达后 T+1 按分层+浏览行为自动推送（附短险链接）→ T+3 用理赔/支持内容建立信任再转化；已转化用户打标签进入下一段旅程。

该模式被报道为带来保费增幅约400%（样本口径为单一机构案例，需谨慎外推）。

So What（可直接复用）：三个可迁移动作——①欢迎语=第一次分层机会，用它换行为数据而不是直接推销；②T+1/T+3 两段式触达：先转化短险、再用品类信任内容承接，比一次性硬推转化率高且不伤品牌；③把"赠险用户"明确划为轻运营，人力集中在高潜层，避免均质化投入摊薄 ROI。补充一条原则：RFM/CLV 分层适合"培育超级用户"，生命周期分层适合"智能化运营"，两者要配对使用，不要只做其中一套。

工具侧：AI 理赔把"体验"变成可量化指标

中国太保"海豚IC"医疗险智能理赔平台由60名理赔/医学专家与AI工程师组成跨界团队打造，将AI嵌入理赔全流程并由医学专家实时修正输出，医疗险理赔差错率降至0.2‰（约为行业平均的1/7），2025年处理超70万件，案均用时压缩至6分钟以内，全年发现有效风险线索超8,000件、助力减损千万元以上。

So What：这套组合拳同时改善三个指标——差错率（体验/投诉）、时效（NPS）、风险线索（减损=赔付率）。建议对标建一张"理赔三指标看板"：差错率、案均时效、单案风险线索命中率，用同一套口径月度复盘，比笼统的"理赔满意度"更能推动跨团队协同。

为什么"综合赔付率41%"不能直接用来判断产品贵不贵

先拆口径。综合赔付率 = 赔款支出 ÷ 已赚保费。在短期健康险里，这个指标同时被三件事影响：

  • 费用结构：渠道佣金与获客成本前置，费用率高则赔付率必然被压低。41%的中位数并不等于"41%赔出去、59%是利润"，其中大头是费用。
  • 业务年期结构：新单占比高的公司，保费先收、赔案后至，当年赔付率天然偏低（准备金未释放）；业务越成熟，赔付率越接近真实。这是"34家赔付率下降"最可能的解释之一，未必都是风控变好。
  • 再保与回溯调整：分出再保会同时影响分子分母，出现负赔付率（6家）通常是摊回赔款大于当期自留赔款的结果，而非经营异常。

实操建议：看赔付率必须三件套一起看——①综合赔付率，②费用率（含渠道+管理），③业务年期/新单占比。三者相加才是"综合成本率"的真相。若只看单一赔付率做产品决策，容易出现"赔付率降了→以为风控成功→实际是费用涨了+新单变多"的误判。

对应到我们的40%赔付率目标：分子端（责任调整、核保收紧、理赔风控、健康管理控费）与分母端（保费扩面）要分开归因。建议月度归因表固定四栏：责任/核保贡献、理赔风控贡献、健康管理贡献、保费结构贡献，避免把"分母变大"误记成"风控有效"。
