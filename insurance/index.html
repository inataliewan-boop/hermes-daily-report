📋 行业动态

中保协三季度发布会：保费微增、赔付快跑、费用压降
前三季度保险业原保费收入5.26万亿元（同比+0.9%），赔款与给付支出1.94万亿元（同比+3.9%）；人身险公司寿险与长期健康险责任准备金超28万亿元（较年初+12.7%）；「报行合一」推动手续费及佣金支出同比下降5.2%（财产险-3.1%、人身险-6.4%）。
So What：赔付增速已达保费增速的4倍以上，行业利润空间同时被「赔付上行+费用压降」双向挤压。对健康险条线而言，责任调整、核保风控等控赔动作与续保率、新单放量等扩分母动作必须同步推进——这正是2026年赔付率考核的核心逻辑。

🏛️ 政策新规

中保协重磅发布：医疗险示范条款＋商保药品推荐清单（第一版）
为落实金融监管总局《关于推动健康保险高质量发展的指导意见》，中保协制定《一般商业医疗保险（短期/长期）示范条款》《城市定制型商业医疗保险示范条款》与《商业健康保险药品保障推荐清单（第一版）》，首批58款药械入围；后续将建立清单动态调整机制，深化与卫健、医保部门协作。
So What：条款标准化后，医疗险竞争焦点将进一步从「条款表述」转向「责任设计＋药品清单运营＋就医服务」。药品清单的动态进出机制，是保司与创新药械企合作支付的新入口，值得产品与BD条线重点跟踪。

💡 产品亮点：众民保（带病体普惠医疗险）四年拆解

  • 目标人群：带病体/非标体——既往症、慢病、高龄等被传统健康告知拒之门外的群体。
  • 产品设计：免赔分层＋DRG住院成本管控＋院外药械支出约束＋再保分保＋慢病管理配套；以AI应用识别个体健康差异，适配差异化保障。
  • 差异化：用「可投」换「可控」——以严重既往症除外与高免赔控制逆选择，用真实赔付案例建立非标体信任。
  • 市场反馈：四年累计数据亮眼（101岁投保、单人获赔183.5万），但专家评价其仍是一年期高免赔的「过渡方案」，长期可持续依赖定价经验与数据开放。
So What：带病体产品的竞争本质是控赔工程学：谁先把「核保识别—责任分层—医疗管控—再保兜底」跑成闭环，谁才能在万亿关口后的非标体市场立足。

📱 用户运营专栏：私域「三层潜力分层」方法论（保费增幅400%案例）

水滴式分层：把人力配到转化率最高的人群
① 高潜力用户（已购多份医疗险/重疾险）：企微1V1＋人工顾问实时回访，主攻重疾加保与年金/寿险交叉销售；② 中潜力用户（持单一医疗险）：人工电话外呼，转化重疾险与家庭单；③ 边缘用户（赠险获取）：机器人外呼轻度运营。分层之上再按场景细分（车主、宝妈、银行、单身、养老等人群包），叠加普通/中等/高潜力等级，实现「分层×场景」矩阵运营。
So What：健康险私域可在「购买潜力」维度上叠加「健康状态」维度做双层分层：高潜力×慢病人群优先推送带病体可投产品，高潜力×健康体主推加保与家庭单——分层颗粒度决定转化上限。

📐 精算小课堂：费率可调长期医疗险的「暴露结构演变」

保证续保的时间陷阱：健康体脱退、患病体沉淀
长期医疗险保证续保意味着理赔人群可继续续保：承保初期全员经核保筛选为健康体，随时间推移自然分化——健康体因「转化为患病体」或「费率增长/调费带来的选择性退保」持续脱退；患病体因首次患病后持续治疗比例高而不断沉淀，占暴露人数的比重逐年抬升。人均赔付成本随之结构性上行：健康体低发生概率、低成本；患病体高频率、高成本。
So What：① 赔付率恶化是费率可调长期医疗险的内生现象，不是运营失误；② 调费是续命工具但会触发健康体选择性退保，形成「调费→好体退出→更需调费」的逆选择螺旋；③ 对冲手段是把调费与续保激励、健康管理服务绑定，延缓暴露结构的底层化——这也是监管鼓励「长期保证续保＋费率可调」设计时必须同步思考的精算配套。
