📋行业动态

前三季度保险业原保险保费收入5.26万亿元，人身险回暖、产险承压
金融监管总局数据显示，2026年前三季度保险业原保险保费收入5.26万亿元。人身险板块回暖，财产险增长承压；同期监管部门向人身险公司下发《关于开展“快返型”产品排查整改的通知》，要求原则上不得新报备第三个保单年度末现金价值超过已交保费的产品，存量问题产品原则上主动停售。
So What：开门红节奏与产品形态再收紧，健康险作为价值型业务在人身险盘子里的话语权进一步提升；关注银保渠道受限后，个险/互联网渠道的健康险增量空间。
📎 [金融时报/ZAKER](https://jrj.wuhan.gov.cn/ynzx_57/xwzx/202610/t20261026_2868123.shtml) · 2026-10-26
第三届四明保险论坛聚焦“以人为本，推动健康险高质量发展”，中国人寿承办
10月15日宁波第三届四明保险论坛暨中国保险学会2026年学术年会期间，监管、行业协会、保司与学术机构共议商业健康险高质量发展路径。中国经济网同期报道，中国人寿积极探索健康险高质量发展路径，强调从产品供给向服务生态延伸。
So What：“以人为本/服务生态”是当前监管与行业对健康险的主流叙事，产品+健康管理服务捆绑成为大公司健康险竞争的标准打法，中小公司和互联网平台需要差异化切口。
📎 [新华网/中国经济网](https://app.xinhuanet.com/news/article.html?articleId=20261017a00e2e20cd974f4fb6b2c92a945b2851) · 2026-10-17
前三季度新能源商业车险签单保费同比增长18.6%，“保险版ABS”登记规模超1300亿元
财险端结构性亮点：新能源车险延续高增长（+18.6%）；保险资产登记交易领域前三季度“保险版ABS”登记规模超1300亿元，险资服务实体经济的资产证券化通道加速放量。
So What：财险增长引擎从传统车险向新能源切换的确定性增强；健康险团队可对照思考：健康险的“新能源时刻”就是带病体/老年/non-standard人群的普惠保障。
📎 [中国经济网](http://finance.ce.cn/insurance1/scrollnews) · 2026-10-27

🏛️政策新规

金融监管总局修订发布《财产保险公司保险产品开发管理规定》（金规〔2026〕9号）
10月9日对外发布修订后的《财产保险公司保险产品开发管理规定》，共8章41条，自2026年11月起施行，2017年版开发指引同步废止。新规明确保险利益、损失补偿、诚实信用、射幸合同和风险定价五大开发原则，并列示八类禁止开发情形，重点禁止开发偏离保障本源的产品。
So What：虽直接约束财险，但“产品开发五大原则+八类禁止情形”的监管框架大概率向人身险/健康险产品开发对标迁移，与健康险产品备案、条款设计直接相关，建议提前自查在售健康险产品责任表述与定价逻辑合规性。
📎 [腾讯新闻/新浪财经/NFRA](https://finance.sina.com.cn/roll/2026-10-10/doc-iniutqmf2088667.shtml) · 2026-10-09
监管排查整改“快返型”产品，叫停现金价值超已交保费的产品形态
监管要求人身险公司原则上不得新报备第三个保单年度末现金价值超过已交保费的产品，存量类似产品主动停售。业内指出这是在2027年“开门红”前拆除规模冲量引信，银保渠道短期承压。
So What：储蓄型业务再度被“挤水分”，行业资源将进一步向保障型（健康险）倾斜，2027年开门红健康险或成为险企真正的增长抓手，健康险条线需提前备货产品与运营资源。
📎 [ZAKER/金融监管动态](https://app.myzaker.com/news/article.php?pk=6ae0161a8e9f0953f15488f3) · 2026-10-26

🔮前沿趋势

安联报告：未来十年中国健康险年均增速8.1%领跑全球
《2026年安联全球保险业发展报告》预测中国保险市场年均增长7.3%领跑全球，其中健康险未来十年预计以8.1%的年均增长率成为最具活力的业务领域；受益于老龄化加速、医疗成本攀升、公共医疗体系承压三重驱动。
So What：国际机构对健康险的长期判断一致向好；与Swiss Re sigma（2025年健康险增速6.0%、为非寿险最快板块）交叉印证——长期赛道确定性强，短期竞争焦点在产品创新与赔付管理。
📎 [央视财经/安联经济研究中心](https://finance.cctv.com/2026/07/06/ARTIQVWh6jmwSXCuVd8bJJCe260706.shtml) · 2026-07-06
Swiss Re：健康险是中国非寿险市场增长最快的板块之一
瑞再研究院2026年中国保险业sigma报告指出，健康险2025年增速6.0%，受补充医疗保障需求强劲带动，持续跑赢非寿险整体（2026年非寿险预计名义增速3.8%）。报告同时提示非寿险保费增速已连续低于GDP增速，结构分化明显。
So What：健康险“跑赢大盘”的相对优势确立，但绝对增速（6-8%）对2026下半年6亿保费目标的达成节奏仍是挑战——增量要靠带病体扩面、场景渗透与续保率提升，不能只靠大盘自然增长。
📎 [Swiss Re Institute](https://www.swissre.com/institute/research/sigma-research/sigma-global-trends-regional-outlooks/china-insurance-2026.html) · 2026-07-17

💡产品亮点

带病体医疗险三大范式：免告知、特定既往症加费/除外、中高端权益升级
当前市场带病体产品形成三条路线：①蓝医保等“免健康告知/带病投保”形态降低投保门槛；②部分产品对甲状腺结节、乳腺结节、胃肠息肉等常见既往症以加费或除外责任承保而非拒保；③众民保中高端2026以私立医院扩容+特药不限清单+CAR-T覆盖做权益纵深。太保同时提示带病人群应优先选择含长期保证续保的产品锁定稳定保障。
So What：免告知类产品定价必须覆盖高逆向选择风险；运营侧的启示是——带病体用户的健康服务黏性（用药管理、康复随访）直接决定续保率，服务即风控。
📎 [太平洋保险/新华网/武汉金融](https://cpic.com.cn/c/2026-09-14/1894633.shtml) · 2026-09-14
百元保费保障再升级：穗岁康模式与百万医疗险对比持续升温
广州“穗岁康”解决带病不能投保、高龄不能投保、医保外病种/药品不能报“四难”，成为惠民保标杆；对比评测类内容显示“最高可投105岁+康复+特药”已成为百万医疗险的主流宣传点。
So What：惠民保与商业百万医疗险的边界在“带病体+高龄”人群上正面相遇，商业产品要用“保证续保+服务体验+高阶医疗资源”构筑差异化，避免与惠民保陷入同质化价格战。

📐精算小课堂：赔付率的“双向警戒线”

短期健康险赔付率低位徘徊背后的定价与费用结构问题
21世纪经济报道调查显示，短期健康险凭借低保费高保额迅速下沉，但赔付率低位徘徊引发“性价比成谜”的质疑：渠道费用占比过高、核保过严、逆选择定价不足并存。行业数据显示部分短期健康险综合赔付率远低于长期医疗险，引发监管对短期健康险赔付率信息披露与产品定价合理性的持续关注。
So What：对赔付率管控有直接参考：赔付率过低同样是风险信号（定价虚高、责任空转），监管已关注短期健康险赔付率披露；建议按“赔付率×费用率×退保率”三因子对在售短险做健康度分级，动态调整渠道佣金与核保政策。
📎 [21世纪经济报道](https://www.21jingji.com/article/20260323/herald/5168b0249c3f96e32cf972ca4853aba9.html) · 2026-03-23
小课堂知识点：赔付率并非越低越好。健康险健康度监控应设“双向警戒线”——赔付率过高提示定价不足或逆选择恶化（需核保收紧/责任调整）；过低则提示责任空转、定价虚高，损害产品竞争力和用户信任，监管亦已关注短期健康险赔付率披露。实操上按【赔付率(事故制/满期) × 费用率 × 退保率】三因子对在售产品做健康度分级，高于上限动核保、低于下线调责任或降佣。IBNR评估需按事故制回溯，避免报案延迟扭曲当期赔付率判断。
