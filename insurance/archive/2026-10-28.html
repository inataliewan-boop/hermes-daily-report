📋 行业动态

前三季度保险业保费5.26万亿元，赔付支出增速快于保费

金融监管总局公布2026年9月保险业经营情况：前三季度原保险保费收入5.26万亿元（财产险1.12万亿、人身险4.14万亿），按可比口径同比增约0.9%；原保险赔付支出1.94万亿元，同比增约3.9%。截至9月末，行业总资产44.61万亿元（+10.4%），净资产4.08万亿元（+8.7%）。

So What：赔付增速持续跑赢保费，承保端"开源"与"控赔"必须双轮驱动——与健康险赔付率管控目标直接同频。
📎 [金融时报/武汉金融局转载](https://jrj.wuhan.gov.cn/ynzx_57/xwzx/202610/t20261026_2868123.shtml) · 2026-10-26

前三季度健康险保费约1.05万亿元，增速快于行业整体

据金融监管总局月度经营情况，2026年前三季度健康险原保险保费收入约10,488亿元，同比增长约4.6%，增速明显高于行业整体的0.9%，仍是人身险板块中景气度最高的险种。

So What：健康险量增的同时，全行业赔付支出增速3.9%高于保费增速——健康险的核心矛盾已从"冲规模"转向"规模与赔付率的再平衡"。
📎 [金融监管总局月度数据·据金融时报](https://jrj.wuhan.gov.cn/ynzx_57/xwzx/202610/t20261026_2868123.shtml) · 2026-10-26

瑞士再保险：2026年非寿险保费增速3.8%，连续第二年低于GDP增速

瑞再sigma报告《2026年中国保险业：增长稳健结构分化》指出，非寿险保费增速自2015-2024年平均9.6%回落至3.8%左右，"报行合一"规范费用竞争的同时也压低了规模扩张速度，行业增长更真实反映需求变化。

So What：规模红利期结束，健康险的边际增长必须来自结构性创新（带病体、中高端、创新药支付），而非行业贝塔。

🏛 政策新规

《财产保险公司保险产品开发管理规定》11月1日施行

金融监管总局10月9日发布修订后的《财产保险公司保险产品开发管理规定》（金规〔2026〕9号，8章41条），11月1日起施行，同步废止2016年《财产保险公司保险产品开发指引》等旧文件。确立保险利益、损失补偿、诚实信用、射幸合同、风险定价五大原则并列明八类禁止开发情形；首次以专章规范附加险开发；要求成立由主要负责人牵头的产品管理委员会，对在售产品动态评估、及时停售不适宜产品。配套产品开发负面清单明确：医疗险条款禁止将处方审核主体约定为第三方服务商而非保险机构，压实保险公司理赔审核责任。

So What：①财险公司健康险产品的开发、评估、退出全流程强监管，短期健康险"重开发轻管理"时代结束；②处方审核责任回归险企自身，理赔风控能力成为硬门槛；③以个险/团险形态经营短期健康险的财险系主体需尽快落地产品管理委员会机制。
📎 [金融监管总局政策法规](https://www.nfra.gov.cn/cn/view/pages/ItemList.html?itemPId=923&itemId=926) · 2026-10-09 / [观察者网·新浪财经](https://finance.sina.com.cn/roll/2026-10-10/doc-iniutqmf2088667.shtml) · 2026-10-10

分红险负面清单：红利承诺不得超利益演示水平

监管产品开发负面清单新增：分红型保险产品说明书中红利分配政策承诺的分配比例，不得超过利益演示的分配比例水平，从源头遏制"画饼式"销售误导；专家指出任何变相承诺收益的行为都是红线。

So What：储蓄型产品销售合规收紧的信号外溢，健康险与储蓄型产品的组合销售话术需全面自查，避免连带合规风险。

🔮 前沿趋势

个人医疗险成为创新药赔付核心增量引擎

《2026中国创新药械多元支付白皮书》：2025年医疗险创新药赔付82亿元，其中惠民保18亿（与2024年持平）、企业补充医疗11亿（持平），而个人医疗险（百万医疗+中高端+带病体专属）达53亿元、同比+40%，贡献近三分之二赔付。截至2025年三季度，国内首款CAR-T产品奕凯达累计惠及超1000位患者，保险赔付覆盖超50%。

惠民保进入存量优化下半场

复旦许闲团队《2025年惠民保知识图谱》：全国累计推出313款地方惠民保，正常运营稳定在202款；2025年前7个月新增仅9款、停售12款（2023年停售超70款），"低增量、低退出"格局确立。超60%停售产品存续仅1期，错位定价与粗放运营是存活关键短板。穗岁康5年年均参保稳定约360万人、累计赔付26.2亿元、减轻个人负担率37.8%，验证精细化运营产品的长期生命力。

So What：惠民保窗口红利消退，产品生存力=定价精准度×运营持续力；与惠民保形成差异化（中高端、带病体专属、服务型产品）才是商业健康险的增量空间。

短期健康险综合赔付率中位数41%：同一指标背后的三种真相

21世纪经济报道统计59家财险公司2025年个人短期健康险综合赔付率：中位数41.09%，34家下降、6家为负、4家超100%。同为"赔付率"，三种情形成因完全不同：①过度承保盈利（赔付率过低甚至为负）往往对应保障责任缩水或高费用渠道结构，牺牲产品竞争力且易触发监管关注；②正常经营区间（40%-60%）对应费用率与赔付率的动态平衡；③承保亏损（超100%）多因带病体扩容后定价因子未同步更新、逆选择加剧。

方法论要点：短期健康险赔付率分析必须拆解为"发生率×案均赔款×报告模式（已付/未决）"三层归因，并区分渠道（个险/团险/互联网）与年龄带的异质性——单一综合赔付率无法指导定价调整。这也是行业"赔付率管控"从总量目标走向"结构化目标管理"的精算基础。

So What：赔付率管控的下一步是"结构性KPI"：分渠道、分病种、分责任设定赔付率走廊（如30%-50%），过低的赔付率同样是预警——它意味着用户未获得实质保障，长期必然被市场与监管双重纠正。
