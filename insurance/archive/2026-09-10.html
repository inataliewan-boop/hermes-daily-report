🏛️ 政策新规

1. 《保险法（修订草案征求意见稿）》公开征求意见 重磅

国家金融监督管理总局 9 月 4 日就《中华人民共和国保险法（修订草案征求意见稿）》公开征求意见，明确五大方向：加强股东穿透监管（将股东、实际控制人纳入监管范围）、完善审慎监管制度、健全风险处置机制、加强保险消费者保护、提高违法违规成本。现行保险法自 1995 年施行，先后于 2002 / 2009 / 2014 / 2015 年四次修改，本次为全面修订。

So What：① 消费者保护写进母法层级，销售误导、代理退保黑产、"全额退保"虚假宣传的处罚上限将抬升，健康险互联网销售的话术合规与留痕需提前自查；② 股东穿透 + 风险处置机制，意味着对偿付能力的监管前置，中小保司扩容与产品激进定价的空间收窄，低价换规模的短险打法会更难走。
📎 新华网 · 2026-09-04 ｜ 人民网 · 2026-09-08 ｜ 金融监管总局原文

2. 《非车险综合治理行动方案》印发 8/21

金融监管总局 8 月 21 日发布方案，着力治理非车险市场无序竞争，聚焦源头治理、深层治理、系统治理；构建"监管指导、公司主责、行业配套"的产品管理体系，以产品源头规范促进市场规范，并强化对经营主体的行为监管。

So What：短期健康险（百万医疗、惠民保等）由财险公司经营，属"非车险"范畴。方案与既有"报行合一"要求一脉相承，费用率与手续费管控进一步收紧，靠高渠道费用冲规模的路径受阻，倒逼产品力与运营效率（续保率、客户体验）成为增长的真正来源——这正是用户运营的用武之地。

📋 行业动态

上半年保险业原保费 3.86 万亿元，赔付增速略快于保费

中国保险行业协会数据显示，2026 年上半年保险市场运行总体平稳、业务结构持续优化：原保险保费收入 3.86 万亿元，同比增长 3.3%；赔款与给付支出 1.4 万亿元，同比增长 3.8%。

So What：行业整体进入"个位数增长 + 赔付增速高于保费增速"的阶段，意味着承保端的利润空间在被压缩。对健康险而言，单纯做大保费规模不再能自动带来好结果，控费（责任调整、核保收紧、理赔风控）与分母扩张必须同时做。
📎 新华网 · 2026-07-31

安联报告：中国保险市场将以年均 7.3% 增速领跑全球

《2026 年安联全球保险业发展报告》显示，2025 年中国保险市场实现 7.4% 的增速，报告预计未来十年中国将以年均 7.3% 的增速领跑全球保险市场。

So What：长期增速预测（7.3%）明显高于当前半年实际增速（3.3%），缺口说明未来增长更依赖结构升级而非自然扩张——健康险、养老、中高端医疗正是这块增量最密集的赛道。
📎 央视网 · 2026-07-06

五大险企银保渠道分化加剧：从"规模逻辑"切换"价值逻辑"

2026 年半年报显示银保合作呈"险企分化、银行提质"格局：平安银保规模保费 664.95 亿元、同比大增 59.9% 领跑；太保等压降趸交、推动期缴转型，价值率改善；另有 3 家险企银保负增长。

🔮 前沿趋势

1. AI 从"炫技"进入"实用落地"：核保助手、智能理赔成主战场

德勤《2026 年全球保险行业展望》指出，生成式 AI 与代理式 AI（Agentic AI）已成为推动行业迈入新阶段的核心动力，但当前多数头部公司更聚焦投资回报明确、风险可控的 AI 实用场景：智能客服机器人、核保助手、智能化理赔流程。在美国市场，欺诈检测被列为未来 12 个月生成式 AI 开发或落地的五大重点领域之一。

So What：行业共识已经从"要不要用 AI"转向"哪个环节 ROI 最高"。对健康险团队，优先级排序建议：核保辅助（带病体精准核保）＞ 理赔风控（反欺诈、过度医疗识别）＞ 客服问答，前两者直接作用于赔付率这一核心考核项。
📎 德勤中国

2. AI 风险本身正在被"保险化"

Gallagher Re《Global InsurTech Report 2026 Q1》指出，市场上将出现多种 AI 保险产品形态：既有作为现有产品附加条款的 AI 责任批单，也有独立承保 AI 错误风险、AI 侵权等一揽子风险的独立产品。InsurTech NY 统计显示，188 份全球保险科技竞赛申请中 71% 提及 AI，但真正拥有付费用户的比例为 45%。

So What：新责任险种意味着新场景，也意味着新的数据与风控需求。对核保端是长期机会；对当下的健康险主业，更有价值的是这份数据揭示的判断——AI 概念不等于商业验证，45% 付费用户率提醒我们内评创新项目时要看真金白银的转化。
📎 Gallagher Re · 2026-05 ｜ InsurTech NY

3. 成本压力成为全球保险业五大挑战之一

安永《2026 全球保险业展望报告》提出五大挑战：AI 转型、成本压力、营运模式优化、先进技术运用、人才与企业文化转型；建议将成本管控与转型投资挂钩，通过跨职能团队、创新中心、合作伙伴关系等优化营运模式。

So What："成本管控与转型投资挂钩"是可直接借用的话术——向管理层申请 AI / 运营投入时，把测算口径绑到可量化的成本节省或赔付改善上，比讲技术先进更有效。

💡 产品亮点

1. 惠民保 2026 版：保障扩容与责任收紧并行，精细化运营成迭代关键

2026 版城市定制型商业医疗保险已进入密集投保期，深圳、青岛、武汉、上海等地陆续开放参保。多地维持保费不变：沪惠保 129 元 / 人 / 年、深圳惠民保 88 元 / 人 / 年、福汉康 2026 为 126 元 / 人 / 年。与价格平稳形成反差的，是责任层面的结构性调整——保障扩容与责任收紧同时发生，行业普遍不再追求参保人数扩张，转而在存量结构中寻找优化空间。

产品设计的三大变化：① 从比保额转向比体验，各地推出加油包、附加险、门诊责任包、健康服务包；② 服务场景向门诊、购药、问诊、陪诊、护理等高频场景延伸（如河北"信惠保"39 元加油包，含互联网门诊常用药报销、住院原研药报销、线上问诊、药品快递到家）；③ 分层保障成为主流，但需警惕逆选择。

So What：惠民保是健康险最真实的"压力测试场"。它给我们的三条可迁移结论：① 低频产品必须靠高频服务撑住留存（对应我们的续保率指标）；② 分层设计要防"高风险集中"——南开大学朱铭来指出，高保障套餐天然吸引带病体和高风险人群，若健康人停在低保障或退出，分层就退化成"把问题换个房间放"；③ 存量结构优化＞增量拉新，与当前监管淡化规模的取向一致。
📎 经济参考报 · 2026-06-29 ｜ 腾讯新闻 · 2026-06-15 ｜ 证券日报 · 2026-05-30

2. 带病人群：超 4 亿人的保障空白，中高端医疗险开始填补

我国带病人群规模已超过 4 亿，其中慢性病患者占绝大多数。长期以来该群体因健康门槛被主流商业健康险排除在外。众民保·中高端医疗险 2026 主打"看得见、用得上"，针对带病人群填补三大保障空白。

So What：带病体可投保是健康险公认的增量蓝海，但核心矛盾是定价与逆选择。能否做成，取决于三件基础设施：医保 / 医疗数据获取、带病体专属核保模型、以及理赔端对既往症的清晰界定。产品创新必须与核保、理赔同步设计，否则爆量即亏损。
📎 中国网财经 · 2026-03-13

3. 百万医疗险选购逻辑收敛为"五个硬指标"

主流测评框架已归结为五条：保证续保是否稳定、免赔额是否友好、特药与外购药是否够用、能否家庭共同投保、理赔是否有人协助。行业测评显示，"把免赔额真正做到 0"成为新一轮产品竞争焦点。

So What：当用户决策从"看保额"转向"看五要素"，产品详情页的信息架构也应随之重排——把这五条前置到首屏，比堆保额数字更能提升转化。免赔额与家庭单是当前最有效的差异化抓手。

👥 消费者洞察

1. 参保逻辑变了：从"怕大病"到"要常用"

惠民保此前最大的痛点是"低频理赔、无感参保"——用户交了钱但一年没用上，续保意愿自然衰减。2026 版产品的应对是把服务延伸到门诊、购药、问诊、陪诊、护理等更高频生活场景，让"用得到"取代"保额高"成为参保理由。

So What：用户的续保决策锚点已经从"风险覆盖充分性"部分转移到"这一年我有没有感知到价值"。据此，健康险的年度价值触达节奏应至少布 4 个触点（保单周年、健康权益激活、理赔 / 问诊体验后、续保前 30 天），每次都有可感知的服务交付。
📎 腾讯新闻 · 2026-06-15

2. 消费者对"理赔协助"的权重显著上升

在百万医疗险等主流产品的选购框架中，"理赔有没有人帮办"被列为独立且权重靠前的决策要素，与续保稳定性、免赔额并列。

So What：理赔体验已成为购买决策变量而非售后期许。把"理赔服务承诺"（如急速赔时效、专人协助）写进商详首屏并配真实案例，是当前转化率提升中投入产出比最高的一类优化。
📎 凤凰网 · 2026-09

🎯 市场机会

1. 健康服务包：把低频保单改造成高频触点

各地惠民保 2026 版密集推出门诊责任包、加油包、健康服务包，已验证"附加服务"能提升参保与续保意愿。这一模式可平移至商业健康险的存量客户经营。

So What：对用户运营的可执行动作：在存量保单上叠加低价高频健康权益（线上问诊、常用药报销、体检），把它作为续保率与客户活跃度的杠杆，而不是单纯的成本项。测算口径建议用"权益使用者的续保率 vs 未使用者"，做出增益归因后再规模化。
📎 经济参考报 · 2026-06-29

2. 带病体市场窗口正在打开，但节奏取决于数据可得性

4 亿带病人群 + 政策鼓励商业健康险与医保错位发展 + 地方（如北京）推动医保数据共享，三者叠加构成清晰的产品窗口。

So What：短期可行路径是先做"可核保的带病体"子集（如单一慢病、指标可控），用健康管理与分段核保控制风险，逐步向复杂带病体扩展；一步到位放开全带病体，赔付率风险不可控。
📎 北京市医保局 · 2026-02-12 ｜ 中国网财经 · 2026-03-13

📱 用户运营专栏

1. 用户分层方法论：CLV 全生命周期 + RFM 模型

在私域精细化运营场景下，核心是先按生命周期阶段（引入期 / 成长期 / 成熟期 / 衰退期 / 流失期）识别用户所处阶段，再用 RFM（最近一次消费 Recency、消费频率 Frequency、消费金额 Monetary）在阶段内做价值分层，从而对不同群体设计差异化的运营目标与触达策略——首单用户转复购、复购用户转意见领袖。

So What：保险是低频行业，直接套用 RFM 会失真，需要做保险化改造：把 F 换成"保单 / 权益交互频次"、M 换成"保费 + 加保金额"、并新增"健康服务使用度"。这样能把"沉默健康人"与"高频互动人"区分开，前者是续保风险最大的一群，应优先干预。

2. 互联网保险私域实战：保费增幅 400% 是怎么来的

行业案例复盘显示，互联网保险通过私域承接（社群 + 一对一）可以把公域投放来的低价线索做二次转化，实现保费量级的跃升，核心在于"把一次成交做成长周期关系经营"，而不是依赖单次投放转化率。

So What：可迁移的关键动作是把获客与经营拆成两个独立考核的环节：获客看首单转化成本，经营看加保率 / 续保率 / 转介绍。当经营环节被单独立指标，团队才有动力做那些"当期不出保费、但决定次年留存"的事。

综合赔付率：健康险最核心的经营刻度

定义与公式：综合赔付率 = （再保后赔款支出 + 再保后未决赔款准备金提转差）÷ 再保后已赚保费。其中未决赔款准备金包含已发生已报告（RBNS）与已发生未报告（IBNR）准备金。

三个易混淆点：

  • 分母是"已赚保费"不是"保费收入"。新保单的未赚部分不计入，所以保费放量当期，赔付率会被"摊薄"（分母先大、赔款滞后）——这是保费扩分母能短期改善赔付率的数学原因，但不是真实经营改善。
  • IBNR 是估计值。理赔报案存在滞后，尤其是住院、重疾类责任，因此当期赔付率的准确性依赖 IBNR 计提方法（链梯法、GLM 等）。计提偏保守 → 当期赔付率虚高；计提激进 → 未来"准备金提转差"转回，赔付率后期自然好转（或反向恶化）。
  • 短期健康险的赔付率波动更大。21 世纪经济报道统计显示超过一半的个人短期健康险综合赔付率出现下降，低位徘徊引发"性价比"讨论——赔付率过低未必是好事，它可能反映保障兑现不足或核保过严，长期会削弱产品口碑与续保。
So What：拆解赔付率恶化时，务必先做量价分离：是风险成本上升（真实恶化，需责任 / 核保 / 理赔 / 健康管理四线并进），还是分母结构变化或准备金计提口径造成的账面波动。把"扩分母"当成唯一解药是危险的——它只能买时间，不能解决问题。
