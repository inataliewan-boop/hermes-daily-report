  • 2026上半年健康险（财险公司口径）同比+15.2%，比行业整体3.3%高出近12个百分点，是当前唯一还在加速的保障型险种。
  • 众安9/10发布尊享e生·中高端医疗险2026系列：超适应症用药可赔、康复责任扩容——把"保不保"往前推到"怎么用得上"。
  • 59家财险公司短期健康险综合赔付率中位数仅41.09%，近六成公司赔付率下降——分子端控住了，分母端（费用与获客）才是真正战场。

📋 行业动态

1. 上半年行业保费3.86万亿、+3.3%；健康险是增速最快的板块

中国保险行业协会数据：2026年上半年原保险保费收入3.86万亿元，同比增长3.3%；赔付支出1.4万亿元，同比增长3.8%。其中财产险公司9846亿元（+2.1%）、人身险公司约2.87万亿元（+3.6%）。协会副秘书长方咏特别指出，财产险公司非车险业务份额已从十年前25%升至54%，其中健康险同比增长15.2%，高于上年同期6.1个百分点；同期分红险保费10126亿元，同比增长94.4%。

So What：健康险的增量基本由财险公司的短期医疗险承接，人身险公司的长期重疾还在失速。短期医疗险的续保运营、赔付纪律和费用率，就是行业当下最值钱的三项能力，与我们的岗位直接对应。

2. 安联报告：中国健康险未来十年年均8.1%，领跑全球

《2026年安联全球保险业发展报告》显示，中国保险市场将以年均7.3%增速领跑全球；其中健康险2025年保费增长2.0%，但未来十年预计以8.1%的年均增长率成为全球最具活力的业务领域，驱动因素为老龄化、医疗成本攀升、公共医疗体系承压与居民支付能力提升。

3. 惠民保进入"低增量、低退出"的稳态

许闲团队《2025年城市定制型商业医疗保险知识图谱》：自2015年深圳首款试点以来累计推出313款产品，当前正常运营202款；2025年前7个月新增仅9款、停售12款（2023年全年停售超70款）。超60%的停售产品只存续了1期。以广州"穗岁康"为例，5年每年参保稳定在360万人，累计赔付90.6万人次、26.2亿元，减轻个人负担率37.8%。

So What：普惠型产品的胜负手已从"能不能上线"变成"能不能续得上"。参保人复购与赔付体验数据，是判断一款惠民保能不能活过第二期的核心指标。

🏛️ 政策新规

1. 《中华人民共和国保险法（修订草案征求意见稿）》公开征求意见

国家金融监督管理总局于2026年9月4日就保险法修订草案公开征求意见。同日发布《银行保险机构信息披露管理办法（征求意见稿）》。两项基础制度同日征求意见，是近年少见的组合拳。

So What：保险法修订会沿着"合同订立—销售适当性—理赔时效—消费者保护"这条链传导，产品条款表述、健康告知问询、免责与等待期措辞都可能需要重写。建议提前把现行条款里"表述模糊、依赖解释"的责任项清单化，等正式稿出来批量复核。

2. 健康保险高质量发展方向已明确：按风险类别定价 + 费率可调 + 个人账户

在《关于推动健康保险高质量发展的指导意见》框架下，监管鼓励：长期医疗险按风险类别定价、开展费率调整；支持开展个人账户式长期医疗保险业务；加快研究出台浮动收益型健康保险配套业务细则。产品供给端鼓励开发惠及带病群体、罕见病群体的商业医疗险，支持全面开展人寿保险责任与护理支付责任转换，并鼓励以自主协商谈判、按疗效付费等灵活支付方式把医疗新技术、新药品、新器械纳入保障。

德勤《2026年全球保险行业展望》指出，生成式AI与代理式AI已成核心动力，亚太头部保司已落地智能客服、核保助手与智能化理赔流程；在美国市场，欺诈检测被列为未来12个月生成式AI落地的五大重点之一。德勤同时提醒：成效取决于数据质量、系统现代化与安全体系，"数据分散+历史遗留系统"仍是主要障碍。NTT DATA《Insurtech Global Outlook 2026》则给出更硬的判断——行业处于结构性拐点，风险积累速度快于韧性建设速度。

2. 医疗险的竞争轴正在从"保不保"转向"定价是否够细"

随着长期医疗险费率可调机制与按风险类别定价被明确鼓励，行业逻辑正在从"一款产品覆盖尽可能多的人"转为"同一款产品对不同风险类别给不同价格"。此前众安产品负责人在接受采访时也坦承，26版产品整体收紧、把较重的带病体排除在外——这正是风险边界在试错中收敛的过程。

So What：未来一年的产品差异不在责任表，而在风险分层颗粒度：健康告知分层、阶梯等待期、既往症清单、首年赔付比例过渡。谁把这些工具组合得细，谁的赔付率就稳。

🎯 市场机会

机会一：精算与核保能力将成为短期医疗险的护城河

上半年健康险15.2%的高增速吸引了所有财险公司入场，但赔付率中位数只有41.09%、且出现6家负值与4家超100%的两极分化。分子（赔付）已经通过核保收紧普遍控住，下一轮拉开差距的一定是费用率与续保结构——也就是用户运营团队的战场：把获客成本摊到更长保单周期上，只能靠续保率。

机会二：护理支付责任转换打开"保险+养老"的衔接场景

监管支持全面开展人寿保险责任与护理支付责任转换业务，叠加地方长护险制度落地（如新疆方案），寿险存量客户存在被重新激活的可能。对健康险团队而言，护理与康复服务可以作为高频触点，撬动中老年客户的保额提升与家庭单扩展。

📱 用户运营专栏

可迁移的分层转化范式：水滴的"按潜力分配运营强度"

  • 高潜层（自购多份医疗险/已购重疾）：企微1V1 + 人工顾问实时回访，目标是重疾加保、年金与寿险交叉销售。
  • 普通层（持有一份医疗险）：人工电话销售，导向重疾转化与医疗险家庭单。
  • 长尾层（赠险获得）：机器人外呼轻度运营，只做基础唤醒。
  • 分层之后再分层：从数据中心切出车主、宝妈、银行、单身、养老等场景人群，再分为普通/中等/绩优/高绩优四档。
  • 行为标签回流：企微通过欢迎语推H5或小程序，按页面行为筛选高优用户、打行为标签回流数据库，沉淀成标准转化SOP。
So What（可直接对照自查）：①运营强度是否与用户潜力匹配，还是所有人一套SOP？②赠险/低潜客户是否占用了过多人工成本？③H5与小程序的行为数据，有没有真正回流成标签与二次触达依据？

📐 精算小课堂

短期健康险综合赔付率：41.09%的中位数该怎么读

21世纪经济报道统计59家财产险公司2025年全年个人短期健康险综合赔付率：中位数41.09%，34家（近六成）较2024年下降，6家为负值，4家超过100%。这组数字里藏着三个容易误读的点：

  • 负值不等于没赔。综合赔付率的分母是已赚保费，分子是赔付支出（含未决/IBNR）；当保费高速增长、且未决准备金被大幅释放时，短期出现负值在数学上成立。它反映的是"当期确认口径"，不是"这一年真的收大于支"。
  • 中位数41%≠行业健康。赔付率低可能来自三处：核保收紧（真本事）、责任缩水（把风险移出保障范围）、或费用前置（把成本记到费用率而非赔付率里）。只有前一种是可持续的。
  • 看赔付率必须配费用率。综合成本率 = 综合赔付率 + 综合费用率。短期医疗险的线上获客成本高，赔付率压到41%而费用率居高不下，一样会亏损——这正是"分子控住之后，战场转到分母"的含义。

延伸：精算界正在把"客户终身价值"写进定价

美国意外险精算师协会（CAS）2026年费率制定研究项目明确征集客户终身价值（Customer Lifetime Value）定价方案，项目完成截止日为2026年9月30日。方向是从"单期赔付率定价"转向"跨期续保与交叉销售价值定价"——对健康险的启示是：一个续保3年的客户与一个只保1年的客户，应该值不同的获客成本。
