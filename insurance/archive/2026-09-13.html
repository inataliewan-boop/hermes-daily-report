📋 行业动态

2026上半年保险业原保费3.86万亿元，健康险增速领跑非车业务

中保协数据显示，上半年原保险保费收入3.86万亿元，同比增长3.3%；赔款与给付支出1.4万亿元，同比增长3.8%。财产险公司非车险业务份额由十年前的25%提升至54%，其中健康险同比增长15.2%，增速较上年同期高6.1个百分点。外资保险公司市场份额升至9.7%。

So What：健康险是当前非车业务中增速最快的主力赛道，分母扩张逻辑清晰；但"高增速+高赔付"并存，赔付管控能力才是分水岭。

《2026年安联全球保险业发展报告》指出，健康险在中国是重要保险品类而非小众业务，2025年中国健康险市场保费增长2.0%。受人口老龄化加速、医疗成本攀升、公共医疗体系承压等因素驱动，未来十年中国健康险市场预计以8.1%的年均增长率领跑全球；未来十年全球保费池新增5.26万亿欧元，中国贡献亚洲半壁江山。

So What：长期天花板被国际机构确认，但短期增速已回落至个位数——"长坡厚雪+短期换挡"，意味着竞争将从抢规模转向拼产品结构与医疗控费。

🏛️ 政策新规

《关于推动健康保险高质量发展的指导意见》落地深化，四大险种分线规划

金融监管总局《意见》对健康保险四大类险种——商业医疗保险、商业长期护理保险、失能收入损失保险、疾病保险——分别明确发展重点，并提出推动健康保险与健康管理融合，构建"事前预防、事中管理、事后保障"相结合的新型健康服务保障体系。到2030年，团体与个人健康保险协同发展，多层次健康保险市场格局基本形成。政策要点包括：鼓励长期医疗保险按风险类别定价、健全长期医疗险费率调整机制、支持个人账户式长期医疗险、平稳有序开展城市商业医疗保险、鼓励开发惠及带病群体与罕见病群体的产品。

So What：这是健康险未来五年最核心的政策母文件。其中"按风险类别定价+费率调整机制"直接关系长期医疗险的产品结构与续保定价能力；"个人账户式长期医疗险"是尚未被充分开发的形态。

🔮 前沿趋势

趋势一：从"事后补偿"到"事前干预"，健康险与健康管理融合成为主线

监管明确支持通过提供医疗、康复、护理等服务的形式履行健康保障责任，推动健康风险减量。德勤《2026年全球保险行业展望》指出，生成式AI与代理式AI已成为推动行业迈入新阶段的核心动力，亚太头部险企已落地智能客服、核保助手与智能化理赔流程，欺诈检测被列为未来12个月生成式AI落地的五大重点领域之一。

So What：控费不再只靠核保收紧，健康管理（用药依从、慢病干预）正在成为赔付率的结构性解法——这与"7月终极赔付率"改善路径高度一致。

💡 产品亮点

拆解：尊享e生·中高端医疗保险2026系列 —— 把"超适应症用药"写进责任

目标人群中高端医疗需求人群、重症治疗患者及其家庭

产品设计针对重症治疗中常见的"超适应症用药"难题，在符合法律法规和条款约定的前提下，将医生开具的、超出药品说明书适应症范围的合理治疗用药纳入理赔范围；同时将保障从手术本身延伸至术后恢复周期，升级术后康复住院保障。

差异化行业普遍以"药品说明书适应症"为赔付边界，超说明书用药常被拒赔；该责任直接对准临床实践与条款文本之间的落差，属于"理赔体验型创新"而非"保额堆叠型创新"。

市场反馈产品于2026外滩大会期间发布，与其2026中期业绩中健康生态COR改善至92.7%形成呼应；中高端线主打医疗资源（特需部/国际部/VIP部）与服务体验差异化。

So What：可复用方法论——当保额竞争触顶后，创新空间在"条款与真实临床的缝隙"里。超适应症用药、术后康复周期、康复护理是最容易被低估的三块赔付感知洼地。

📱 用户运营专栏

方法论：CLV全生命周期分层 × RFM价值分层，双模型识别"该重投的人"

GrowingIO方法论指出，全域运营时代需用两套模型配合：CLV（用户全生命周期）分层用于智能化运营，按引入期/成长期/成熟期/衰退期制定差异化策略；RFM模型（最近消费R、消费频次F、消费金额M）分层则更倾向于培育超级用户，识别高价值人群并向上迁移。

So What：健康险可直接映射——R=最近一次续保/加保时间，F=家庭单成员数，M=累计保费。健康险复购天然低（多为年缴），因此F与M的权重应高于R，否则模型会持续误判健康用户为低价值。

📐 精算小课堂：综合赔付率里的 IBNR，为什么短期健康险的赔付率会"看似很低"

综合赔付率 =（再保后赔款支出 + 再保后未决赔款准备金提转差）÷ 再保后已赚保费。其中未决赔款准备金包含已发生未报告未决赔款准备金（IBNR）。IBNR 是为"事故已经发生、但尚未报案或尚未结案"的赔案计提的准备金——它天然具有估计属性，需依靠赔付发展三角（Development Triangle）等方法外推。

So What：短期健康险（百万医疗、惠民保）保单期限仅一年且不含保证续保，其已赚保费确认极快，而 IBNR 计提受制于理赔时效。当业务处于高速增长期时，新单保费计入分母的速度远快于赔案进入分子的速度，赔付率会被"增长稀释"而系统性偏低。因此：
  • 比较赔付率必须同口径同期间，跨公司跨规模直接对比容易误判；
  • 增长放缓的年份赔付率会"跳升"，本质是前期业务成熟而非经营恶化；
  • 评估产品真实盈利能力应看"事故年赔付率/终极赔付率"，而非当期财务口径。
参照数据：恒安标准人寿披露的综合赔付率2026年上半年为29.1%，较2025年全年23.6%上升，其口径明确含IBNR准备金；行业层面，59家财险公司2025年全年个人短期健康险综合赔付率中位数为41.09%，其中34家同比下降、6家为负值、4家超过100%，离散度极大。
