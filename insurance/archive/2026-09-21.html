📋 行业动态

惠民保进入"存量精耕"：核心矛盾从规模转向普惠性与可持续性的平衡

人民日报9月14日刊文指出，惠民保已从"跑马圈地"转向"存量精耕"，行业必须回答"如何在特药扩容、待遇提升的同时，避免健康人群退出、带病体人群沉淀"。同期北京普惠健康保2026年度特药清单调整完毕：共176种（国内特药71种、海外特药65种、特药2共40种），国内特药新增14种，主要为肿瘤药品。

So What：惠民保的竞争焦点已从"谁保得多"变成"谁管得住风险"。对我们意味着两件事——一是特药清单扩容会持续抬高赔付成本，二是"健康人群退出"是续保率与赔付率恶化的共同源头，精细化运营（分层触达、健康服务留存）是唯一解法。

2026医保"双目录"谈判收官：12个药品进入商保创新药目录价格协商

9月9日，2026年国家医保药品目录现场谈判竞价结束。9月5日至8日，上百家企业参与，124个目录外药品进入基本医保谈判竞价，覆盖肿瘤、罕见病、慢性病及儿童用药；另有12个药品进入商保创新药目录价格协商。按国家医保局规则，同时具备两个目录准入资格的药品先参加医保谈判，失败后再进入商保价格协商，协商成功并签署承诺书方可纳入商保创新药目录。首版商保创新药目录（2025年）纳入19种药品。

So What：商保创新药目录进入第二年，正在把"特药责任"从营销话术变成有标准清单、有价格锚的硬责任。产品端需提前评估：目录内药械的纳入节奏、赔付影响与直付/垫付服务能力，是本轮产品迭代的胜负手。

前8个月保险业被罚没近2亿元，"双罚制"下54人被禁业

经济参考报9月14日报道：今年前8个月，保险机构（含分支机构）收到来自金融监管总局及派出机构、央行、证监会罚单合计899张，同比增长10.44%，罚没金额约1.95亿元。财险公司486张、寿险公司408张；中国人寿、人保财险、平安产险罚单数量居前三（64张、55张、51张）。销售行为违规是重灾区，54名从业人员被禁业，多人被"终身禁业"。

So What：罚单结构说明监管重心仍在销售端与费用端。健康险线上营销的动作（页面表述、告知与免责提示、可回溯留痕）属于高敏感区，产品商详审核与客服话术应做一次自查，避免踩在"销售违规"主线上。

So What：健康险是当前行业少有的"高增速+高关注度"赛道，也意味着竞争与合规压力同步上行。增速来自规模扩张，但赔付率与留存指标才是真正决定业务质量的变量。

🏛️ 政策新规

监管高层定调"健康保险提质扩面"，为"十五五"划定方向

金融监管总局副局长丛林在国新办新闻发布会上明确提出"鼓励健康保险提质扩面"。央视网、证券时报梳理认为，这为"十五五"时期健康险划定核心方向：在规模增长放缓、结构深度调整的节点，行业需从"量的扩张"转向"质的提升"与"面的拓宽"，直面覆盖不均、产品同质化、医保协同不足三大瓶颈。

So What："提质扩面"= 扩人群（带病体/高龄/新市民）+ 提质量（保障深度、服务与理赔体验）。这是一条明确的产品与运营路线图，与我们的带病体与中高端产品线方向一致。

监管叫停健康险"理财化"：账户式产品专项整改，热销产品迅速下架

据证券时报报道，部分公司将增额终身寿险的理财逻辑嫁接进健康险，以"医疗金账户"为名把报销范围放宽至配镜、推拿、医美等非医疗消费，并通过高现金价值制造"存钱"幻觉。监管启动专项整改，厘清"真账户"与"伪账户"边界——账户资金应严格限定于真实医疗支出。业内指出，分红型重疾险、个人账户式长期医疗险等创新方向的配套细则与产品落地仍待推进。

So What："个人账户"是政策鼓励方向，但被异化为理财工具就会立刻被纠偏。产品设计中的账户资金用途、现金价值结构属于合规高压线，创新可以走，但不能往"存钱"上靠。

🔮 前沿趋势

趋势一：从"赔付型保险"到"健康管理型保险"

专家观点认为，健康险下一阶段的关键词是"提质扩面"，路径之一是把产品从单纯的事后赔付，转向"保障+健康管理服务"的一体化供给，以服务降低发生率、提升用户黏性。这与监管鼓励将医疗新技术、新药品纳入保障、采用按疗效付费等支付方式形成呼应。

So What：健康管理服务不再是赠品，而是赔付率的"阀门"和续保的"抓手"。运营侧应把服务使用率当成与转化率同等重要的指标来盯——用得上的服务才留得住人。
📎 央视网·财经 · 2026-09-15

趋势二：AI 从"降本工具"走向"业务接口"

国际视角：NTT DATA《Insurtech Global Outlook 2026》（6月10日）判断行业正处结构性拐点，未保险损失与责任类索赔上升，被动等待不再可行；Insurance Technology Trends 2026 指出生成式AI已从"新奇"变为核心运营工具，Allstate 由AI系统每天生成超5万封客户邮件；Caliber 总结 Insurtech Insights USA 2026 时区分"防御型AI（降本增效）"与"进攻型AI（增长与关系）"两种策略。

So What：AI 的价值衡量标准正在从"省了多少人力"转向"改了什么结果"。理赔自动化（一次报案材料率、自动审核率、时效）是可被直接量化的进攻型指标，也是续保与口碑的因果上游。

短期健康险综合赔付率：为什么"过低"同样是问题

按《中国银保监会办公厅关于规范短期健康保险业务有关问题的通知》（银保监办发〔2021〕7号）要求，保险公司须披露个人短期健康险业务综合赔付率，公式为：

综合赔付率 =（再保后赔款支出 + 再保后未决赔款准备金提转差）÷ 再保后已赚保费

其中未决赔款准备金包含已发生未报告（IBNR）准备金。理解要点有三：①分母是已赚保费而非保费收入，未到期部分不计入，因此新单高速增长期赔付率会被"稀释"；②分子含准备金提转差，业务快速扩张时IBNR计提增加会推高当年赔付率，反之则有释放效应；③行业参照：财险公司2025年个人短期健康险综合赔付率中位数41.09%、131家险企口径41.73%、中国人寿47.98%，而业内认为70%左右更接近合理区间。

延伸：长期医疗险自2019年《健康险管理办法》修订首次明确可费率调整，2020年4月《长期医疗保险产品费率调整有关问题的通知》细化触发条件与调费规则后落地，目前保费规模已超百亿量级，产品形态覆盖10-20年中长期至保终身、含特需责任与普惠类产品。费率可调机制是长期医疗险可持续经营的关键——它把"未来医疗通胀"这一系统性风险从保险公司单边承担，转变为可依规则与客户共担。

So What：看赔付率必须配套看口径与业务阶段：新单高速增长会天然压低当年赔付率，不能据此认为"业务很健康"；反之赔付率短期冲高也需区分是IBNR计提变化还是真实风险恶化。做赔付率管控时，报表口径（事故制/已赚）与产品结构变化必须同步拆解，否则容易得出错误结论。
