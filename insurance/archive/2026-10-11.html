🏛️政策新规

产品开发示范条款医保联动

金融监管总局修订《财产保险公司保险产品开发管理规定》，11月1日起施行

2026年10月9日，国家金融监督管理总局正式修订发布该规定，2026年11月1日施行，同时废止2016年旧版指引。此次修订补全财险产品乱象监管漏洞，明确8类禁止开发的违规产品，并首次对附加险开发设置专章规范，压实公司产品开发主体责任、强化消费者权益保护。对经营健康险、意外险等财险类产品的机构，意味着附加险设计与报备需更严格的合规自查。

So What｜健康险/百万医疗类附加险（门诊加油包、特药包等）将成为合规审查重点，产品上架前需专项复核附加险条款边界与禁止性情形。 📎 新浪财经/观察者网 · 2026-10-10

中保协就《一般商业医疗保险（短期）示范条款》公开征求意见

中国保险行业协会在深入研究论证、广泛征求意见基础上，形成《一般商业医疗保险（短期）示范条款（草案征求意见稿）》。示范条款落地后将成为短期医疗险条款的行业基准，有助于统一理赔口径、减少条款争议。

So What｜短期百万医疗是众安核心品类，示范条款将直接影响条款措辞与销售话术，建议提前比对自有条款差异项。 📎 中国保险行业协会 · 2026-09-16

医保局密集发文：十五五规划、长护险支付管理、DRG/DIP 3.0

《全民医疗保障"十五五"规划》印发（08-19）；《长期护理保险支付管理工作的指导意见》发布（08-26）；按病组和病种分值付费3.0版分组方案留待落地（09-02）。基本医保改革持续深化，为商业健康险留出"衔接互补"的空间。

So What｜DRG/DIP 3.0落地将改变医院诊疗与用药结构，直接影响百万医疗的赔付成本与产品责任设计，需关注目录外保障的机会窗。 📎 国家医疗保障局 · 2026-08~09

保险业前5月保费增超4%，健康险结构分化

人身险与财产险公司合计健康险原保费5521亿元、同比+3.9%。其中财产险公司健康险保费1644亿元、同比大增14.56%，而人身险公司健康险保费同比微降。财产险公司成为健康险增长的主要引擎。今年政府工作报告首次"点题"商业健康保险，提出加快发展、推动创新药械高质量发展。

So What｜财险系健康险（百万医疗、门诊险）放量明显，产品与运营竞争将进一步向财险主体集中，需强化差异化责任与续保留存。 📎 证券时报

安联报告：中国健康险未来十年年均8.1%增速领跑全球

《2026年安联全球保险业发展报告》指出，2026年中国健康险保费增长2.0%，未来十年预计以8.1%年均增速领跑全球，是最具活力的业务领域，动力来自人口老龄化、医疗成本攀升、公共医疗体系承压与居民健康意识觉醒。

So What｜长期赛道确定性高，短期增速换挡（2.0%）说明进入"精细化经营"阶段，粗放拉新让位于存量价值经营。 📎 央视网 · 2026-07-06

Swiss Re sigma：2026年中国保险业"增长稳健、结构分化"

瑞再研究院预计2026年非寿险名义保费增速约3.8%，"报行合一"规范费用竞争、使增长更真实反映需求。健康险与家庭财产险有望保持稳健增长。

So What｜"报行合一"持续压制费用驱动的规模扩张，渠道合规与真实需求转化能力成为分水岭。 📎 Swiss Re Institute · 2026-07

🔮前沿趋势

健康险三股力量对决：平台联盟 vs 央企国家队

平安（+蚂蚁）阵营与保险央企（国寿、人保健康）在健康管理赛道正面交锋。蚂蚁阿福用户规模达1.5亿、单日健康咨询人次近百万级；平安好医生联合北大医疗、诊锁界启动诊所网络共建，构建"北大医疗输出临床路径+平安数字化运营+健康险支付"的四方协同生态。核心分歧在于：健康服务优先服务C端留存，还是先增强B端保司与医疗机构合作意愿。

So What｜医险融合从概念走向落地，健康管理公司+直付网络成为竞争壁垒；对用户运营的启示是"高频健康服务触点"是提升留存与续保的关键抓手。 📎 新浪财经 · 2026-09-15

InsurTech 2026：AI驱动转型，但数字体验满意度下滑

全球保险科技市场预计2026年规模达488.7亿美元，2026-2034年CAGR约36.69%。但J.D. Power 2026美国保险数字体验研究显示，保险公司数字服务满意度下降4分至695/1000——数字渠道普及但体验质量参差。

So What｜数字化投入不等于体验提升，"把常用任务做得更简单"比堆功能更能提升满意度；AI客服/AI核保需以完成率而非覆盖率为考核。 📎 Openkoda / J.D. Power · 2026

💡产品亮点

尊享e生·百万医疗险2026：首个把"康复医疗"打包进保障的百万医疗

目标人群：需长期康复的特定疾病术后患者（脑卒中、严重骨折、恶性肿瘤术后等16种）。产品设计：确诊后180天内，在合作的33家指定康复医院治疗可报销80%并享直付与上门康复指导，年度限额100万；无指定机构地区可在二级以上公立普通部或183家指定民营医院按60%赔付。医院范围新扩至183家私立（民营）医院。差异化：百万医疗首次将康复治疗纳入责任，标志从"保治疗"迈向"保恢复"。

So What｜用康复医疗+民营医院网络拓宽了差异化护城河；同类产品需评估是否跟进，但康复责任的成本与欺诈风险（诱导康复、过度治疗）需配套风控。 📎 众安保险官网 · 2026

众民保·中高端医疗险2026：填补带病人群三大保障空白

覆盖民营（私立）医院增至183家，肿瘤特药不限清单，涵盖国内已获批7款CAR-T疗法；一般疾病开放特需部/国际部/VIP部作为可选责任，重大疾病自动拓展。在保障扩容同时，进一步明确严重既往症清单、针对一般既往症引入阶梯式等待期、对择期手术设置首年赔付比例过渡——"加法做保障、精细化做管理"。

So What｜带病体产品可持续性的关键在风险边界界定（既往症清单+等待期+赔付过渡），为带病体健康险提供了可复用样本。 📎 武汉市金融局转载 · 2026-03

👥消费者洞察

惠民保进入"存量优化"期：低增量、低退出

截至2025年7月31日，全国累计推出313款地方性惠民保产品，当前正常运营稳定在202款。2025年新增仅9款；停售从2023年的70余款降至2025年前7月的12款。超60%的停售产品存续仅1期——运营越久越稳。广州"穗岁康"5年参保稳定在360万人/年，累计赔付26.2亿元，减轻个人负担率37.8%。

So What｜惠民保从"跑马圈地"转向"精耕续保"，续保率与赔付管控成为产品生死线；对商保公司的启示是长期运营能力>短期获客。 📎 经济参考报 · 2026

市场涌现大量免健康告知医疗险，通过扩展承保年龄至70岁、住院门急诊及院外购药保障、重疾0免赔等设计，覆盖中老年与亚健康人群。

🎯市场机会

机会一：康复医疗责任 = 差异化的下一个战场

尊享e生2026把康复医疗纳入百万医疗，"保治疗→保恢复"打开新责任空间。康复需求刚性、支付方明确（商保直付）、可绑定指定康复机构形成网络壁垒，是继特药、质子重离子之后又一个可做深的责任模块。

建议｜评估在家庭门诊/中高端产品线试点"特定疾病康复"责任，先用小额限额试水，配套康复机构白名单与治疗方案审核控费。

机会二：健康管理服务接续"高频触点"

蚂蚁阿福1.5亿用户、单日近百万咨询量，验证了健康服务高频触点的价值。健康管理/问诊/早筛等高频服务可提升用户月活与续保意愿，是健康险留存运营的关键增量。

建议｜把"健康服务使用率"纳入续保预测模型，对高频服务用户做续保定向权益，对低频沉默用户做唤醒运营。

📱用户运营专栏

水滴私域打法：保费增幅400%，核心是"分层+标准转化SOP"

水滴按用户价值分层运营：对持有医疗险+重疾险的高潜力用户，用企微1V1+人工顾问回访做加保与交叉销售；对持有一份医疗险的中等客户，用人工电销向重疾险/家庭单转化；对赠险获取的边缘客户仅做机器人外呼轻运营。客户通过企微好友申请后自动触达欢迎语（H5/小程序），根据行为数据打标签回流数据库，升级线索至网销专人跟进，形成可复制的转化SOP。

So What｜关键不是"做私域"，而是"分层精度+自动化SOP"。把行为标签→线索流转→人工跟进做成标准化流水线，才能规模化提升转化与续保。 📎 人人都是产品经理

方法论：CLV全生命周期 + RFM模型培育超级用户

用CLV（用户全生命周期）做智能化运营分层，用RFM（最近消费/频率/金额）识别高价值用户并培育"意见领袖"。在全域运营与私域精细化场景下，先识别生命周期与价值层级，再制定差异化策略，把首单用户逐步转化为复购用户。

So What｜健康险可复用：以保单持有数+服务使用频次+理赔/续保行为构建类RFM标签，驱动交叉销售（医疗险→重疾险→年金）与续保分层。 📎 GrowingIO · 2026-04-19

📐精算小课堂

短期健康险综合赔付率为何"低位徘徊"？

综合赔付率 =（再保后赔款支出 + 再保后未决赔款准备金提转差）÷ 再保后已赚保费，其中未决赔款准备金含IBNR（已发生未报告准备金）。2025年全年59家财险公司短期健康险综合赔付率中位数仅41.09%，34家同比下降，6家为负值、4家超100%，分化极大。对比2026年上半年：复星联合健康63.07%、大都会(再保前39.3%/再保后17.4%)、恒安标准人寿29.1%。

So What｜赔付率高低是费用结构、渠道模式与风险管理的综合结果。对运营端：低赔付率既可能是优质风控，也可能意味着保障不足引发"性价比"质疑；对定价端：IBNR估计的精算假设直接影响当期赔付率呈现，跨期比较需注意口径（再保前/后、含不含IBNR）。 📎 21世纪经济报道 / 复星联合健康
