📋行业动态

◆上半年保险业原保费收入3.86万亿元，同比增长3.3%

中国保险行业协会发布数据：2026年上半年原保险保费收入3.86万亿元（+3.3%），赔款与给付支出1.4万亿元（+3.8%）。其中财产险公司9846亿元（+2.1%），人身险公司约2.87万亿元（+3.6%），外资保险公司市场份额升至9.7%。

So What：人身险增速（3.6%）显著高于财险（2.1%），健康险作为人身险核心品类继续享受结构性增长红利；外资份额升至9.7%，健康管理服务能力强、产品差异化明显的机构仍有入场空间。

◆非上市人身险公司上半年净利增长109.4%，财险公司合计净利超89亿元

投资收益回暖叠加新会计准则全面执行，非上市人身险公司上半年净利润同比增长109.4%；77家非上市财险公司上半年合计净利润超89亿元。险资亦加速布局新兴产业，曲线入股宇树科技，不断扩大战新产业配置。

So What：投资端回暖为负债端让利（如健康险定价利率、服务投入）创造空间；新会计准则下利润波动放大，健康险"死差+费差"的精细化经营价值凸显，靠投资收益率讲故事的时代正在过去。

🔮前沿趋势

◆安联：中国健康险未来十年预计以8.1%年均增速领跑全球

So What：短期增速放缓（2.0%）≠长期空间见顶。健康险进入"存量优化+结构升级"阶段，增长引擎从"流量红利"切换为"人口结构红利"，长期医疗、护理、带病体是确定性赛道。

◆带病体投保需求爆发，"免健康告知"≠"带病全赔"的用户认知差待弥合

📱用户运营专栏

◆私域如何撬动保险运营：续约率从72%提到80%，8个点意味着什么

保险私域具有天然优势：①续约是刚需场景，用户不会删掉续保对接的企微；②用户池均为已购用户，画像与标签数据基础扎实；③可依托数据中心按场景（车主/宝妈/银行/单身/养老）与价值层（普通/中等/绩优/高绩优）做四层细分运营。案例显示某保险工具将用户续约率从72%提升至80%。

So What：对健康险（尤其百万医疗、惠民保）团队：续保率是利润核心。把"续保提醒+保障检视+家庭单加保"做成企微标准SOP，比拉新ROI更高；按场景分层（如宝妈→少儿医疗加保）是现成的交叉销售路径。

◆水滴私域分层运营拆解：保费增幅400%的运营机制

三层运营策略：①高潜力优质用户（多份医疗险/已有重疾险）→企微1V1+人工顾问深度运营，主攻重疾加保与年金/寿险交叉销售；②中等潜力客户（单份医疗险）→人工电话销售转化家庭单；③赠险边缘客户→机器人外呼轻度运营。每层再按场景与价值继续细分，并沉淀标准转化SOP（欢迎语→H5/小程序行为追踪→打标→分层触达）。

So What：健康险运营可直接复用的框架：用"持有保单数+保障缺口"代替"购买意向"做分层；把运营动作（企微/电销/外呼）与用户价值强绑定，避免对高价值用户用低成本触达、对边缘用户过度投入。CLV+RFM是落地分层的好工具。

◆短期健康险赔付率：为什么财险公司（55.48%）远高于寿险公司（27.77%）？

以2022年138家险企扫描为参照：80家人身险公司平均赔付率27.77%，财险公司平均55.48%，9家公司超100%"红线"、最高达797%。差异根因在于经营基础：寿险公司在定价、核保、理赔数据积累上更成熟，而财险公司短期健康险经营时间短、经验数据与定价能力欠缺，叠加渠道成本结构差异。

So What：赔付率是健康险定价能力的镜子。2026版人身险负面清单进一步收紧：费用补偿型医疗险须区分社保/非社保定价、健康管理服务费用占比不得过高、禁止缺乏经验数据时盲目设定高额给付限额。定价团队应把"经验数据积累→分层定价→动态调费"作为核心能力建设，而非依赖市场均值拍脑袋。
