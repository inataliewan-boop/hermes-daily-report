中金重磅研报：宠物险是“联合健康”模式的更优试验田，众安卡位领先

中金公司10月22日发布宠物保险专题研报，核心判断：宠物险商业模式与人类健康险高度同构（均以医疗费用支付为核心场景、依赖医疗服务网络），但中国宠物险比健康险更易跑通“联合健康”模式——宠物医疗格局分散（2024年CR2仅11.8%）、缺乏稳定支付方，保司可“销售保单+集采服务”与医疗体系合作共赢。关键数据：预计2030年中国宠物险市场规模有望达百亿元左右；众安2025年宠物险总保费12.96亿元，同比+88.2%，市场份额行业第一，约1.8万家合作宠物医疗门店；平安财险侧重生态协同发力该赛道。

So What：对众安而言，宠物险是健康险运营能力（医疗网络管理/理赔风控/用户分层）的“低冲突迁移场景”——不与医保争支付方、客群年轻高粘性。中金点出的“理赔数据反哺风控模型→提升体验与黏性→规模与生态壁垒”飞轮，与健康险的带病体运营逻辑同源，团队方法论可复用。

富卫集团领衔：团险沉寂三十年后二次出发，预期年增速超11%

21世纪经济报道，因“盘子大、转型难”被称为“大象”的团体健康险正经历转身：富卫集团（1828.HK）10月12日相关动作引发市场关注，行业预期团险业务年增速超11%。团险长期受制于盈利模式粗放、价格战与服务能力不足，此轮重启的动力来自企业员工福利升级与团体健康管理的渗透。

So What：团体健康险若重启增长，企业客户 salud(健康) 服务需求将同步放大——团险获客单位成本低于个险，是健康管理与用药服务B端化的天然入口，值得关注B端健康服务合作伙伴生态。

2025健康保险保障指数0.6428：年轻化+“高意愿、紧预算”双特征凸显

南开大学金融学院联合小雨伞、手回保险10月13日发布《2025健康与养老保险保障指数测算研究报告》：①2025年健康保险保障指数0.6428，较2024年提升0.0187；②健康保障结构得分由0.7244升至0.7944，达基本水平的群体占比59.07%（+8.18pct）；③最高得分年龄段由36-40岁前移至26-30岁（0.6676，+0.0463），年轻人配置提速；④需求呈“高意愿、紧预算”——保障责任期望不断扩展，但近八成受访者年度保费预算集中于中低区间。报告建议：责任模块化、保额阶梯化、缴费长期化、加保动态化。

So What：“最高得分年龄段前移5岁”是重要信号——健康险的增量客群正加速年轻化，产品定价、内容种草渠道、触达话术都需要向26-30岁人群倾斜；“高意愿紧预算”印证模块化+动态加保是转化率抓手，与“从卖一个产品到经营一段关系”的用户运营主张一致。

医保基金前三季度收支：支出1.75万亿，结余5513亿

国家医保局10月21日发布数据：2026年1-9月基本医保（含生育保险）统筹基金总收入23028.33亿元，总支出17515.19亿元。其中职工医保统筹基金收入14473.64亿元（支出10044.28亿元，含生育保险待遇支出1010.10亿元）；居民医保统筹基金收入8554.69亿元（支出7470.91亿元）。累计结余约5513亿元。

So What：医保统筹基金支出增速与收入基本匹配、当期仍有结余，短期“医保腾笼”压力可控；但居民医保支出/收入比达87.4%（vs 职工69.4%），居民端基金长期承压更深——这正是商业健康险承接居民大病与自费需求的政策窗口依据。

金融监管总局10月9日修订发布《财产保险公司保险产品开发管理规定》（金规〔2026〕9号），11月1日起施行。明确财险公司经营的短期健康保险与意外伤害保险属于其“人身保险”范畴，纳入统一的条款费率开发管理；列出八类禁止开发情形，强化产品开发主体责任与精算要求。（该新规核心内容已于10/22日报详细报道，今日重点提示生效倒计时。）

宠物险的精算特殊性：身份识别即风控第一道闸

中金研报点出宠物险存在“身份识别环节的技术壁垒”——这正是其精算风控的核心：宠物医疗险面临逆选择+道德风险双重放大（宠物无身份证体系、病历不互通、宠物主可带宠物多处就诊重复理赔）。行业通行做法：①鼻纹/虹膜生物识别投保锁定身份；②等待期+既往症观察期控制逆选择；③与合作医院直连结算锁定诊疗真实性。众安1.8万家合作门店的网络本质是“数据采集网络”——每一笔直连理赔都在训练风控模型。对比健康险：医保数据直连使我们能以理赔经验动态调整核保规则，宠物险的门店直连是同样的逻辑复刻。

So What：“直连结算=数据护城河”这一模型在健康险（医院直付/医保快赔）与宠物险（医院直连）中通用：结算直连度越高，理赔数据越真实完整，风控与定价迭代越快——评估任何医疗支付类业务时，可把“直连率”当作核心运营指标之一。

健康保障指数报告的运营启示：把“卖产品”改造成“经营关系”的四步法

南开大学报告针对“高意愿、紧预算”人群给出的解法，翻译成运营动作就是四步：①责任模块化——把住院/门诊/特药/齿科拆成可勾选模块，降低首单决策门槛；②保额阶梯化——同一产品提供30万/100万/300万梯度，预算敏感用户先入低档；③缴费长期化——月缴替代年缴，把年预算压力拆到12个月；④加保动态化——基于家庭生命周期事件（结婚/生育/购房）触发保障检视与加保提醒。配合26-30岁客群得分最高的发现：年轻客群的首单产品要“轻”，加保旅程要“自动”。

So What：这与CLV+RFM分层方法论同构：低预算新客用“模块化轻产品”建立关系，随生命周期事件与收入增长沿“加保动态化”路径向上迁移——首单不是终点，是分层旅程的起点。建议现有用户旅程的加保触发点对照“生命周期事件清单”做一次补全。
