📋 行业动态

1. 前9个月保费微增0.9%，行业结构分化持续

2026年前三季度保险业保费同比微增0.9%，寿险单月回暖、财险微调。东吴证券预计2027年开门红仍以分红型产品为主；在医保商保合作深化背景下，商业健康险被视为最具潜力的增长板块，险企正通过打通保险、体检、康复、养老、药品、医院链条，构建「健康管理+医疗服务+保险」一站式生态以提高客户黏性。

So What：行业大盘增速放缓，健康险是少数被研报点名的结构性增长赛道；「健康生态黏性」逻辑与用户运营里的生命周期价值经营直接相关。
📎 东方财富网 · 2026-10-25

2. 前三季度「保险版ABS」登记规模超1300亿元

保险资产支持计划（保险版ABS）前三季度登记规模突破1300亿元，保险资金对接实体资产的非标供给持续放量，为险企资产负债匹配提供更多工具。

So What：投资端工具扩容与负债端保费增速放缓形成对照，健康险经营的利源结构中利差重要性上升，赔付管控与定价精细化愈发关键。
📎 中国经济网 · 2026-10-26

🏛️ 政策新规

1. 金融监管总局修订《财产保险公司保险产品开发管理规定》，11月起施行

金融监管总局于10月9日在官网发布修订后的《财产保险公司保险产品开发管理规定》，自2026年11月起施行，对财险公司产品开发管理提出更新要求。同期官网还披露：与财政部、央行联合实施居民购房贷款贴息政策（9月29日）、会同应急管理部等部署2026年安责险事故预防服务（9月底），监管条线动态密集。

So What：财险公司是短期健康险（百万医疗、惠民保共保体）的重要经营主体，新规施行后产品开发、回溯与退出管理趋严；涉及财险渠道报备的短健康产品，上架SOP与产品回溯节点需同步对齐合规口径。
📎 金融监管总局官网 · 新浪财经 · 2026-10-09/10

🔮 前沿趋势

1. 商业健康险「双目录」激活创新药多元支付，个人医疗险成增长主力

《2026中国创新药械多元支付白皮书》显示：2025年医疗险创新药赔付82亿元，其中个人医疗险（含百万医疗、中高端医疗及带病体专属医疗险）达53亿元、同比增长40%；惠民保18亿元、企业补充医疗11亿元，均与上年基本持平。近三分之二的赔付与主要增量来自个人医疗险，惠民保已不是增长主引擎。叠加商业健康险「双目录」推进，药险联动的支付格局正在重构。

So What：产品结构决定创新药支付能力——惠民保进入存量优化，增量要靠个人医疗险的责任设计（外购药械、特药、CAR-T）；这对产品责任迭代与商保目录准入是直接的赛道信号。

2025年医疗险创新药赔付结构（亿元，合计82亿）

2. 安联：健康险是中国最具活力的保险业务

《2026年安联全球保险业发展报告》指出，与全球多数市场将健康险视为小众业务不同，健康险在中国是重要品类；受益于老龄化加速、医疗成本攀升、公共医疗体系承压与居民健康意识觉醒，未来十年中国健康险市场预计以8.1%的年均增速领跑全球。

So What：长期增速预期的锚在「老龄化+支付缺口」，健康险的增长叙事从流量红利转向保障缺口经营，用户教育与健康服务能力是承接关键。
📎 央视财经 · 2026-07-06

中国人寿、国寿资产拟以45.8亿元向国寿集团转让国寿养老超37%股权，国寿集团将接棒成为第一大股东，国寿系养老与健康管理资产整合提速。

So What：头部机构把养老、健康服务资产向集团集中，「保险+养老+健康服务」的生态协同将更紧密，健康险的服务供给能力随之增强。

北京商报报道，信泰保险因违规开展再保险业务、监管套利等问题被监管要求整改，合规经营仍是行业不可触碰的底线。

So What：监管对「形式创新、实质套利」持续高压，产品设计与再保安排的合规审查应前置于方案阶段。

💡 产品亮点

1. 百万医疗险竞争焦点：外购药械从「清单制」走向「处方制」

10月新一轮百万医疗险对比中，以星相守2号、蓝医保好医好药版为代表的产品把竞争焦点放在外购药械责任上：星相守2号住院外购药品和器械不设清单限制，凭医生处方在额度内100%报销、不受社保结算方式影响，恶性肿瘤特药覆盖195种（含3种CAR-T）、200万保额0免赔；蓝医保好医好药版标准版覆盖276种特药，0免赔版额外纳入64种先行区急需进口药（合计约340种），但1万以内外购费用按30%-80%比例报销。

So What：「用得上」正在取代「保额高」成为核心卖点——外购药责任从清单制到处方制，意味着理赔确定性成为新的差异化战场；对产品与核赔口径的协同要求显著提高。
📎 凤凰网 · 2026-10

2. 人保财险「人人安康」2026众享版：带病可保、70岁可投、一般既往症可赔

人保财险8年百万医疗险标杆「人人安康」推出2026众享版，实现三大突破：放宽结节、高血压、糖尿病等常见带病人群投保限制；首次/非续保投保年龄放宽至70周岁；「严重既往症」以外的疾病纳入赔付范围，实现一般既往症可保又可赔。配套专属「理赔明白卡」提升理赔透明度。

So What：「保健康体」走向「保带病体」的跨越由头部财险公司落地验证，带病体定价+核保风控+健康管理闭环成为下一阶段的产品壁垒。
📎 新华网 · 2026-05-30

👥 消费者洞察

1. 投保决策要素迁移：外购药、续保条件与免赔额优先于保额数字

10月各平台百万医疗险投保指南类内容热度上升，健康成年用户的对比焦点集中于外购药是否设清单、特药数量、免赔额结构与续保条件，保障实用性超越保额数字成为决策核心。

So What：内容营销与商详页应把「理赔确定性」翻译成用户语言（凭处方即可报、CAR-T覆盖、0免赔场景），比堆保额更能驱动转化。
📎 凤凰网投保指南 · 2026-10

2. 惠民保基本盘稳固，进入存量优化时代

截至2025年7月末全国累计推出313款惠民保产品，正常运营202款，从增量扩张转向存量优化。广州穗岁康5年来年参保人数稳定在360万左右，累计赔付90.6万人次、金额26.2亿元，减轻个人负担率37.8%；昆明2026年度春城惠民保7月上线，持续放宽参保条件、升级健康服务。

So What：惠民保的价值从「拉新」转向「承接与服务」，与个人医疗险的分层协同（惠民保保基本、商保保进阶）是用户教育的重要叙事。
📎 中国新闻网 · 2026-01-03 · 经济参考网 · 昆明市政府

🎯 市场机会

1. 创新药多元支付：个人医疗险 +40% 增量背后的「药+险」空间

在创新药商保「双目录」与多元支付白皮书的双重催化下，个人医疗险已成为创新药支付的增长主力（53亿元、+40%）。围绕特药责任、外购药械、CAR-T与先行区药品的「药+险」产品设计与服务链路，仍有明显的结构性空间。

So What：把创新药准入能力产品化（目录动态更新、处方流转、直付网络），是产品差异化与理赔体验的共同抓手。

2. 带病体与银发市场：从拒保到「可保可赔」的定价蓝海

人保70岁可投、一般既往症可赔的实践验证了带病体与高龄人群的定价空间；叠加健康管理服务黏性，慢病人群的精细化定价、核保放宽策略与风控模型构成新竞争壁垒。

So What：带病体产品的胜负手不在价格而在「核保放宽的精度+理赔兑现的确定性」，数据能力与服务网络是护城河。

📱 用户运营专栏

1. 水滴私域分层案例：按用户潜力三级运营，驱动加保与交叉销售

水滴的私域打法按潜力分层：高潜力用户（已购多份医疗险或重疾险）采用企微1V1+人工顾问实时回访的深度运营，寻求向重疾加保及年金/寿险交叉销售；中等潜力（持有一份医疗险）由人工电销转化重疾或家庭单；赠险获得的边缘用户仅做机器人外呼的轻度运营。分层内部再按车主、宝妈、银行、单身等标签细分。该案例 reported 保费增幅达400%。

So What：保险私域的核心公式=价值分层×触达方式匹配×合规边界；对健康险，多单识别、续保行为、加购信号是高潜力分层的关键特征，1V1资源应集中投放在头部价值用户。

行业观察显示，2026年私域运营整体增速放缓、合规要求收紧、工具市场洗牌，粗放群发失效；方法论层面，GrowingIO的CLV（用户全生命周期价值）+RFM模型组合被广泛用于识别不同生命周期与价值层级的用户并设计差异化策略。

📐 精算小课堂

短期健康险综合赔付率：低位徘徊意味着什么？

21世纪经济报道统计59家财产险公司2025年短期健康险数据，行业综合赔付率低位徘徊，引发「低保费高保额杠杆模型是否可持续、用户是否真获得保障」的讨论。概念拆解：综合赔付率=（本期赔款支出+未决赔款准备金提转差）÷已赚保费，属满期口径；与事故制口径（已发生赔款÷已赚保费）的差异在于是否包含准备金变动。赔付率持续过低通常指向定价偏高或责任偏窄；持续过高则指向定价不足或逆选择。2026版人身险产品「负面清单」亦强调精算假设不得偏离实际、定价不得失真。

So What：赔付率管理是双向的——既要防恶化，也要防「过度便宜」触发产品回溯与费率调整压力。对短期健康险，建议按产品线分渠道监控满期赔付率，并区分渠道费用率还原「赔付+费用」的真实成本结构。
