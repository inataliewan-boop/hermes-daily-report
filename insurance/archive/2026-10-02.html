🏛️ 政策新规

1. 金融监管总局：推动健康保险高质量发展（9月纲领性文件）

文件提出健康险发展的纲领与方向，核心要点：

  • 定价机制：鼓励长期医疗险按风险类别定价、开展费率调整，支持探索个人账户模式；加快研究出台浮动收益型健康保险配套业务细则。
  • 产品供给：鼓励开发惠及带病群体、罕见病群体的商业医疗险；支持全面开展人寿保险责任与护理支付责任转换业务。
  • 支付方式：鼓励将医疗新技术、新药品、新器械纳入保障，采取自主协商谈判、按疗效付费等灵活支付方式。
So What："按风险类别定价+费率调整"是长期医疗险可持续经营的政策底座，直接指向赔付率恶化的解法；"个人账户+浮动收益"则为健康险资金端打开新形态，值得产品团队提前做定价与准备金模型预研。
📎 方达律师事务所·金融法律监管年度报告(2026)保险业篇 · 2026

2. 两会回溯：5年商业健康险累计赔付近2万亿

金融监管总局披露，过去5年商业健康保险累计赔付近2万亿元，并积累了用于未来赔付支出的 2.79万亿元长期健康险责任准备金；同时推动"打通医保商保数据""拓展创新药械多元化支付方式"等建议落地。

So What：2.79万亿责任准备金是长险负债端的巨大体量，也意味着未来给付高峰的可预测性管理是精算核心；医保商保数据打通将直接改变核保与理赔风控的数据基础。

🔮 前沿趋势

1. 商保在创新药械支付中的"44%责任"窗口

2024年我国创新药械市场规模达 1620亿元：医保支付占44%（约710亿）、个人现金支付占49%（约786亿）、商业健康险仅124亿（7.7%）。若按国际经验将个人自费降至20%、医保维持36%，则商保需承担约44%的支付责任（约4400亿元）。

So What：7.7%→潜在44%的支付占比差，是健康险未来十年最大的结构性增量。能否把特药、CAR-T、质子重离子等高价责任做成"可保、可赔、可控费"的闭环，决定谁能吃下这块蛋糕。
📎 2026年中国商业健康险白皮书 · 2026

2. 全球视角：中国健康险未来十年年均8.1%领跑

《2026年安联全球保险业发展报告》显示，2025年中国健康险市场保费增长2.0%；预测未来十年中国健康险以 8.1%的年均增长率领跑全球保险市场，驱动力为人口老龄化、医疗成本攀升与公共医疗体系承压。

So What：低速当期增长 vs 高潜长期空间的组合，说明"精耕存量、优化结构"是当期主旋律——与赔付率攻坚同频。

3. InsurTech 2026：AI 从"防御"走向"进攻"

国际行业会议共识：AI 应用区分防御型（降本增效、自动化单据）与进攻型（增长、个性化、挖掘服务不足市场）；嵌入式保险、基于使用的定价（UBI式）成为主流趋势。

So What：健康险的AI进攻型应用=核保风控前置+个性化保障推荐+健康管理干预，直接服务"赔付率下降"与"留存提升"两个KPI。

💡 产品亮点

1. 人保财险"人人安康"百万医疗险（众享版）：带病可保、高龄可投

目标人群带病体 + 一老一小。产品实现三大突破：①带病可投（放宽结节/高血压/糖尿病等投保限制）；②高龄可保（首次/非续保投保年龄放宽至70周岁）；③既往症可赔（将"严重既往症"以外的疾病纳入赔付）。同时上线理赔明白卡、理赔流程可视化。

So What："带病体可保可赔"是行业从健康人群红海转向非标体蓝海的标志动作；但需警惕——放宽准入必然带来逆向选择，核保定价与风控能力是成败关键。

🎯 市场机会

1. 非标体/带病体产品线：从"能不能保"到"怎么控费"

监管明确鼓励带病体、罕见病群体商业医疗险，叠加人保、太保等已推出带病可保产品，非标体赛道已从概念走向落地。

So What：机会点不在"放宽告知"本身，而在"放宽后的费率充分性"——建议以风险类别定价+费率调整条款+健康管理干预三者组合，对冲逆向选择带来的赔付率抬升。

2. 特药/创新药械支付闭环：最大的结构性增量

创新药械支付中商保仅占124亿（7.7%），2035年商保潜在支付责任约4400亿。

So What：可优先布局"特药清单+按疗效付费+直付网络"组合产品，把高值药品的支付能力做成差异化卖点，同时通过谈判降价与疗效付费控费。

📱 用户运营专栏

1. 水滴模式：用户分级 + 标准转化SOP

水滴将客户按价值分四层并叠加场景标签（车主/宝妈/银行/单身/养老）：高潜优质用企微1V1+人工顾问深度运营（转化重疾/年金）；中等潜力用电话销售转化家庭单；边缘赠险客群仅用机器人外呼轻度运营。触达节奏标准化：欢迎语自动触达→T+1按分层标签推送带短险链接→T+3用理赔内容建信任并转化。

So What："先分层、再定触达强度"是可直接复用的方法论——把运营预算按用户价值梯度分配，避免对低价值客群过度投入。

2. 金融保险私域：四类人设 + 六类内容SOP

《小裂变金融行业私域解决方案》指出：高客单的理财/保险产品适合专属顾问与知识专家人设（低客单适合种草达人/福利官）；社群内容需覆盖六类——规范型、干货价值型、产品营销型、用户互动型、售后服务型、文化价值观型。

So What：保险天然高客单，"知识专家+专属顾问"人设更匹配；可把"理赔实录/健康科普"作为干货内容主力，兼顾信任建立与转化。

📐 精算小课堂

本期主题：赔付率与定价——80%的偏差来自数据，而非模型

某年保费约3亿元的财险公司，精算总监发现车险赔付率连续三个月超预期、面临亏损；核对定价模型发现预测与实际偏差超10个百分点——问题并非模型，而是核心业务系统输出的赔付率计算口径存在严重偏差，导致输入模型的数据本身失真。

关键结论：金融数据分析在精算领域的"下限是数据质量，上限是业务理解"。行业普遍误以为更复杂的机器学习模型能解决定价不准，但实际上约80%的定价偏差根源在数据本身。

So What（直接对应赔付率KPI）：在推动"赔付率下降"前，先做一次口径审计——事故制赔付/已赚口径是否一致、IBNR计提是否充分、是否混入了未满期与费用项。口径不统一，任何"赔付率改善"都可能是数字幻觉。建议：①统一赔付率口径并固化取数逻辑；②对短期健康险关注"综合赔付率"负值与超100%的异常公司；③2025年财险短期健险赔付率中位数仅41.09%（59家），近六成下降——低赔付率背后可能同时存在"定价偏高、保障不足"的消费者质疑。
